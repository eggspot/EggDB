# Code of conduct

EggDB follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in every project space: issues, pull requests, discussions and anywhere someone represents the
project.

In short: be welcoming, kind and patient; disagree about ideas, never attack people; no
harassment, no sexualised language or imagery, no publishing others' private information. The
maintainers may remove, edit or reject contributions that break these rules, and may ban those
who repeat them.

To report a problem, contact the maintainers privately through GitHub (a private message to an
`eggspot` organisation owner). Reports are handled confidentially, and the Covenant's
enforcement guidelines (correction, warning, temporary ban, permanent ban) apply.
