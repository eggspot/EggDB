## D964 Hibernate's dialect and Exposed's registration for EggDB's JDBC driver — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D16 and D182's JVM list

- **Hibernate.** `drivers/java/hibernate` holds `app.eggspot.eggdb.hibernate.EggDbDialect`, Hibernate's own community
  SQLite dialect at the SQLite language level EggDB's SQLite dialect speaks (3.45), and `EggDbDialectResolver`,
  registered through `META-INF/services`, which picks it for connections whose `DatabaseMetaData` names the database
  `EggDB` (as EggDB's JDBC driver does), so `hibernate.dialect` can be left out. It is a separate source tree with
  Hibernate on its class path, so the JDBC driver itself depends on nothing. `check/HibernateCheck.java` builds a
  session factory on `jdbc:eggdb:`, creates the schema, persists two entities and reads them back in order.
- **Exposed.** `drivers/kotlin/exposed/EggDbExposed.kt` registers `jdbc:eggdb` with Exposed's SQLite dialect
  (`Database.registerJdbcDriver`) and connects; `ExposedCheck.kt` creates a table, inserts and selects. Exposed goes
  through JDBC, so it uses the Java driver, not the Kotlin JNI binding.
- jOOQ runs on any JDBC connection with `SQLDialect.SQLITE`, and Spring Data JPA on Hibernate, so both need checks, not
  code; R2DBC needs a reactive driver of its own and is left.
