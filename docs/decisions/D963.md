## D963 A Doctrine DBAL driver for the PHP driver — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D16 and D182's PHP list

- `drivers/php/src/Doctrine` implements Doctrine DBAL 4's driver interfaces over the FFI `EggDB\Connection`:
  `Driver` extends Doctrine's own `AbstractSQLiteDriver`, so Doctrine's SQLite platform, schema manager and exception
  converter apply unchanged; `Connection`, `Statement`, `Result` and `Exception` are thin wrappers (D16).
  `DriverManager::getConnection(['driverClass' => EggDB\Doctrine\Driver::class, 'path' => 'app.db'])` (or
  `'memory' => true`) connects in EggDB's SQLite dialect.
- `Statement` takes positional (`?`) and named (`:name`) parameters, rewriting names to positional order outside quoted
  text, and binds by Doctrine's `ParameterType` (booleans as 1 and 0, integers as integers, streams read whole).
  `Result` keeps the last statement's rows and answers row counts from the command tags; `lastInsertId` asks
  `last_insert_rowid()` on the same session.
- **Left.** Laravel's Eloquent connects through PDO, so it needs a PDO driver, a C extension of PHP's; Doctrine ORM
  runs on this DBAL driver.
- `tests/doctrine_check.php` runs inserts, `lastInsertId`, updates, named parameters, a transaction and the query
  builder when Doctrine DBAL is installed, and skips otherwise.
