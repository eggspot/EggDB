## D1257 More ODBC escape functions: intervals, positions, trigonometry and names — Decided by the code-only session (2026-11-18, D355); roadmap M6 ODBC driver (D1255)

- **What users get.** `{fn TIMESTAMPADD(SQL_TSI_..., n, ts)}` and `{fn TIMESTAMPDIFF(SQL_TSI_..., a, b)}` from seconds to years, three-argument `LOCATE`, `DAYOFWEEK` (1 is Sunday), `DAYOFYEAR`, `QUARTER`, `SIN`, `COS`, `TAN`, `COT`, `ASIN`, `ACOS`, `ATAN`, `ATAN2`, `DEGREES`, `RADIANS`, `DATABASE()` and `USER()` run on every dialect. `SQLGetInfo` adds their bits, the `SQL_FN_STR_LOCATE_2` bit D1255 left out, and answers `SQL_TIMEDATE_ADD_INTERVALS` and `SQL_TIMEDATE_DIFF_INTERVALS`.
- **How.** MySQL connections get MySQL's own functions. Elsewhere, an interval in seconds, minutes, hours, days or weeks is added as a count of seconds (`INTERVAL 'n seconds'`, SQLite's `'n seconds'` modifier) and differences are whole periods of elapsed seconds, truncated; months, quarters and years add months and count calendar months between the two dates (year times 12 plus month), divided and truncated. A position from a start is found in the rest of the text and moved back by the start, 0 when absent. SQLite has no `cot`, so `COT` is `1.0 / tan(x)`; SQLite's `DATABASE()` is `'main'` and its `USER()` is empty, as SQLite has no users.
- **Left.** `SQL_TSI_FRAC_SECOND`; `WEEK`, `DAYNAME` and `MONTHNAME`, whose numbering and names differ between dialects; `RAND`, `TRUNCATE`, `REPEAT` and `INSERT`, which SQLite lacks.
- **Proof.** A unit test translates each new function for the families that differ.

**Status:** code written, unbuilt (code-only mode, D355).
