## D1320 WebAssembly functions returning a table — Decided by the code-only session (2026-11-25, D355); follow-up of D1318

- **What users get.** A `LANGUAGE wasm` function may be declared `RETURNS TABLE (name type, ...)` over the types a wasm function returns, and its rows have those columns in `FROM`. The export follows D1318's convention, with the row flag first and then each column's values in order (one value for a number, an address and a length for `text`, `varchar` and `bytea`); `CREATE FUNCTION` checks that shape.
- **How.** The values after the flag are split per column and each converted as a single result is (D793, D862); a one-column table is a set of that column's type, as PL/pgSQL treats it.
- **Left.** Nothing of its own.
- **Proof.** A test module returning an `i32` and its `i64` square gives the rows 1|1, 2|4 and 3|9, and a declaration whose second column does not match the export is refused.

**Status:** code written, unbuilt (code-only mode, D355).
