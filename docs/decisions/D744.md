## D744 `CREATE EXTENSION eggdb_features`: a feature store with online serving — Decided by the code-only session (2026-11-12, D355); roadmap M12, a feature store with low-latency online feature serving (D31, D55)

- `eggdb_features` keeps feature views (a source query, its entity and event-time columns and an optional time to
  live) and an online table of each entity's newest features, in SQL and PL/pgSQL:
  - `define_view(name, source_query, entity_column, time_column [, ttl])`;
  - `materialize(name)` runs the source and upserts each entity's row into `eggdb_features.online` when it is not
    older than the stored one, returning the rows read; a pg_cron job keeps it fresh;
  - `online_features(name, entity)` serves the stored features as `jsonb` (with `event_time`) by one primary-key
    read, or null past the time to live;
  - `features_at(name, entity, time)` returns the newest source row at or before `time` (within the time to live),
    the point-in-time read training sets need.
- Features are `jsonb` objects of the source row's other columns, so a view may have any columns. Entities are
  matched as text.
- Left: streaming updates from change capture, feature services joining several views, and batch point-in-time
  joins of a whole entity table.
