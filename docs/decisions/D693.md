## D693 XMLQUERY and XMLEXISTS — Decided by the code-only session (2026-11-12, D355); roadmap M9 XML documents (D38), M10 Oracle's XML functions

- `XMLQUERY('path' PASSING [BY VALUE] xml RETURNING CONTENT [NULL ON EMPTY])` (Oracle, and the SQL standard's
  `RETURNING SEQUENCE`) evaluates the path with D690's XPath 1.0 and returns the selected nodes serialized one after
  another, or the string form of a string, number or boolean result. An empty result is an empty string, or `NULL`
  with `NULL ON EMPTY`.
- `XMLEXISTS('path' PASSING [BY REF | BY VALUE] xml)` (PostgreSQL and Oracle) is true when the path selects
  something, as `xpath_exists`.
- Both are read in the PostgreSQL and Oracle dialects where the other SQL/XML forms are (D454). Only XPath 1.0 is
  understood, not XQuery's FLWOR expressions, and the result is text, as there is no `XMLType` yet.
