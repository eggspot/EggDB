## D1321 Oracle VPD dynamic and context-sensitive policies — Decided by the code-only session (2026-11-25, D355); follow-up of D851 (D186)

- **What users get.** `DBMS_RLS.ADD_POLICY` takes Oracle's default `policy_type => DBMS_RLS.DYNAMIC`, and `CONTEXT_SENSITIVE` and `SHARED_CONTEXT_SENSITIVE`, besides the static types of D851: the policy function is called at every statement that runs while the policy is enabled, so a predicate built from tables, package state or application contexts follows them from one statement to the next, as in Oracle. An empty or `NULL` predicate restricts nothing, a failing policy function fails the statement with `ORA-28112`, and an unknown `policy_type` is refused with `ORA-28104`. `ENABLE_POLICY` and `DROP_POLICY` work as for static policies.
- **How.** A dynamic policy is stored in `eggdb_internal.oracle_rls_dynamic` with its function, and its row-security condition is `eggdb_oracle_dynamic_predicate('<schema>', '<object>', '<policy>')`. Before each statement, a session whose database has enabled dynamic policies calls their functions once (in the Oracle dialect, as the session's own role) and keeps the predicates for that statement; the condition reader parses the kept predicate in the Oracle dialect. A database without dynamic policies pays one key lookup per session until a policy is added in the process. While a policy function runs, dynamic policies do not restrict its own queries, so a function may read the table it guards; a condition whose predicate was not worked out for the statement lets no row through. Context-sensitive policies are called every statement too, which gives the same rows as Oracle's re-evaluation when the context changes.
- **Left.** Column-level VPD (`sec_relevant_cols`), policy groups, and the `DBA_POLICIES` view.
- **Proof.** An Oracle test adds a dynamic policy whose function reads a floor from a configuration table, sees the visible rows change when the configuration changes between two statements of the same session, and sees every row once the policy is disabled; a type that does not exist is refused.
