## D1334 Leaf pages stored compressed, with their freed blocks punched out — Decided by the code-only session (2026-11-25, D355); roadmap M2 "Compressed leaf pages and log records" (D40, D171)

- **What users get.** `Options::compress_pages(true)` stores B-tree leaf pages compressed on disk whenever that frees at least one 4 KiB block of the page, and gives the freed blocks back to the file system, so a database of compressible rows takes less disk. It pays with 16 KiB and larger pages on file systems with holes; with 4 KiB pages no page qualifies, and nothing changes. Pages are compressed as commits write them, so an existing file shrinks as its pages change. Off by default.
- **The stored form.** A new page flag, `PAGE_COMPRESSED` (2): after the 16-byte header, the compressed body's length as four little-endian bytes, the body (bytes 16 to the end of the page) as one LZ4 block from our own codec (D171), then zeros. The page checksum covers the stored form, so damage is caught before decompressing; a body that does not decompress to exactly the page reads as a checksum mismatch. Reading expands the page in place and clears the flag, so the cache and every structure above it see whole pages as before. The superblock carries a new incompatible feature, `COMPRESSED_PAGES` (bit 4), from the first commit with compression on, so releases that do not know the flag refuse the file instead of reading compressed pages as damaged ones.
- **Holes.** `File::punch_hole` (default: keep the bytes, which read the same) frees the zero tail after each in-place write of a compressed page: `fallocate(FALLOC_FL_PUNCH_HOLE | FALLOC_FL_KEEP_SIZE)` on 64-bit Linux and Android, `fcntl(F_PUNCHHOLE)` on whole 4 KiB blocks on macOS and iOS; a file system that refuses holes is not an error. The log keeps the stored form at full page length, so recovery and the in-place writes from the log are unchanged.
- **Encrypted files** keep their pages whole: a compressed length would tell an observer how compressible each page's contents are.
- **Left.** Log records shortened to the compressed length (the log still writes full pages), compression chosen per column (that belongs to columnar storage, M11), Zstandard for cold pages, and Windows sparse files (`FSCTL_SET_ZERO_DATA`).
- **Proof.** A page cache test with 16 KiB pages commits four compressible leaves, finds the flag in the file and the feature bit in the superblock, reopens and reads every page back whole with no flag.

**Status:** code written, unbuilt (code-only mode, D355). A file format change: its own security review comes with the build-and-fix pass (D35).
