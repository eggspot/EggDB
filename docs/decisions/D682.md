## D682 A Flux core over /api/v2/query — Decided by the code-only session (2026-11-12, D355); roadmap M16, InfluxQL and Flux (D220)

- The observability listener answers `POST /api/v2/query` (a JSON body with `query`, or `application/vnd.flux`) with
  InfluxDB 2's annotated CSV (`#datatype`, `#group`, `#default` and a header per table schema), so Grafana's Flux data
  source and InfluxDB 2 client libraries can read the metrics tables. Flux's language specification is public and
  MIT-licensed.
- `eggdb-observability/src/flux.rs` parses one pipeline of calls with named arguments (strings, numbers, durations
  such as `1h30m`, RFC 3339 times, `now()`, booleans, lists and `(r) => ...` predicates with `and`, `or`, `not`,
  `exists`, comparisons and `=~`/`!~` regular expressions over `r.column` and `r["column"]`).
- Rows are Flux's narrow rows: one per measurement, field and time, with `_start`, `_stop`, `_time`, `_value`,
  `_field`, `_measurement` and the tags, grouped into one table per series. `from()` then `range()` are required;
  the `filter()` calls right after `range()` are pushed into SQL per measurement and field: conditions on
  `_measurement` and `_field` are decided before any query runs, so only matching measurements and fields are read,
  and the rest becomes the `WHERE` clause.
- Then, in order, in Rust: `aggregateWindow(every:, fn:, createEmpty:)` with `_time` at each window's stop and empty
  windows filled (0 for `count`, null otherwise); `mean`, `sum`, `count`, `median`, `spread`, `stddev`, and the
  selectors `first`, `last`, `min` and `max`; `group(columns:)`; `sort(columns:, desc:)`; `limit` and `tail`;
  `keep` and `drop`; and `yield(name:)`.
- Windows and aggregates run over the rows SQL returns rather than in SQL, so a query reads at most a million rows
  and makes at most 100,000 windows per table; pushing them down is later work. `filter()` after a transformation,
  `map()`, `pivot()`, `join()`, variables, several `yield`s and the other standard-library packages are not
  supported yet and answer with an error naming the function.

**Status:** code written, unbuilt (code-only mode, D355).
