## D1217 ALL ROWS PER MATCH, running measures, skip modes and anchors in MATCH_RECOGNIZE — Decided by the code-only session (2026-11-17, D355); roadmap M16, `MATCH_RECOGNIZE` for complex event processing (D55, D768, D1067)

- **What users get.** `ALL ROWS PER MATCH [OMIT EMPTY MATCHES]`: one output row per row of each match, with the source's columns and the measures; measures are `RUNNING` by default there (computed over the match up to the current row, so `CLASSIFIER()` is the current row's variable and `COUNT(DOWN.*)` counts the `DOWN` rows so far) and `FINAL` when written so, as SQL:2016 and Oracle define them. `AFTER MATCH SKIP TO NEXT ROW`, `TO FIRST var`, `TO LAST var` and `TO var`, with Oracle's errors for a skip to the match's own first row or to a variable the match has no row of. `^` and `$` anchor a pattern to the partition's first row and past its last.
- **How.** The matcher (`row_pattern.rs`) gets zero-width `PartitionStart` and `PartitionEnd` instructions and `matches_skipping`, which `row_pattern_matches` takes as an optional third argument (`'to next row'`, `'to first DOWN'`, ...). The clause's rewrite (D1067) reads one match's rows between a start and an end; for `ALL ROWS PER MATCH` it joins the matches to the numbered source rows (`mr_all`, numbered in a hidden column so `mr_a.*` shows only the source's columns) and a running measure uses the current row's number as its end, a final one the match's end.
- **Left.** `$` inside the SQL clause (EggDB's lexer reads `$` as the start of a dollar quote, so it works through `row_pattern_matches` and `eggdb_streams.match_recognize` only), `SUBSET`, `PERMUTE`, exclusion (`{- -}`), `SHOW EMPTY MATCHES` and `WITH UNMATCHED ROWS`, and Oracle's column order for `ALL ROWS PER MATCH` (partition and order columns, then the measures, then the rest; EggDB gives the source's columns, then the measures).
- **Proof.** `row_pattern.rs` tests (each skip mode, its errors, both anchors) and `streams.rs` clause tests (`ALL ROWS PER MATCH` with a running classifier and count beside a `FINAL LAST`, `TO NEXT ROW` finding overlapping matches, `^`).
