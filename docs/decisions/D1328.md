## D1328 PostgreSQL's inet, cidr, macaddr and macaddr8 types — Decided by the code-only session (2026-11-25, D355); roadmap "PostgreSQL's network address ... types" (D19)

- **What users get.** Columns, casts and literals of `inet`, `cidr`, `macaddr` and `macaddr8` in PostgreSQL's dialect, as Django's `GenericIPAddressField`, Rails' `inet` columns and network inventories use them. Values print as PostgreSQL prints them (`10.1.2.3` without a full mask, `192.168.1.0/24` for `cidr '192.168.1'`, `08:00:2b:01:02:03` for every MAC spelling), compare in PostgreSQL's order (family, then the common network bits, then the mask length, then the whole address), sort and index in that order, and travel on the wire with their OIDs (869, 650, 829, 774) in text and binary form.
- **Functions and operators.** `host`, `masklen`, `set_masklen`, `netmask`, `hostmask`, `broadcast`, `network`, `family`, `abbrev`, `inet_same_family`, `inet_merge`, `macaddr8_set7bit`; the containment operators `<<`, `<<=`, `>>`, `>>=` and `&&` and their functions `network_sub`, `network_subeq`, `network_sup`, `network_supeq`, `network_overlap`; casts between `inet` and `cidr` and between `macaddr` and `macaddr8`. `cidr` input follows PostgreSQL's classful rule for abbreviated addresses and refuses bits right of the mask with PostgreSQL's message and detail.
- **How.** A value is kept in its canonical text (as `tsvector` is, D195) under a new `DefinedValue::Network`; stored rows tag each type (35 to 38). Index keys and equality use a key built from the family, the network bits one symbol per bit, an end mark and the full address, which sorts exactly as the comparison does, so `inet` and `cidr` values that PostgreSQL calls equal match. `pg_type` lists the four types and their arrays.
- **Left.** `inet` arithmetic (`+`, `-`, `~`, `&`, `|`), `trunc(macaddr)`, GiST and SP-GiST network operator classes, and arrays of these types as their own element types.
- **Proof.** Unit tests for canonical forms, the order and its key, every function and the binary form's round trip; a session test stores the three types, orders by an indexed `inet` column and runs `<<`, `<<=`, `host`, `masklen` and `network`, and refuses a `cidr` with host bits.

**Status:** code written, unbuilt (code-only mode, D355).
