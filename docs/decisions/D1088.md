## D1088 Suspend and resume for iOS background limits and Android Doze — Decided by the code-only session (2026-11-13, D355); roadmap M17 (D41, D59, D222)

- **The failure modes.** iOS ends an app suspended while holding a lock on a file in a shared app-group container (`0xdead10cc`) and suspends apps seconds after they leave the screen; Android's Doze and app standby stop work at any moment. Committed data is already safe (every commit is durable when it returns), so the risks are being ended for a held lock, a long replay at the next start, and an app extension changing the file while the app sleeps.
- **The API.** `Database::suspend` waits for the writer as `begin_write` does, checkpoints, syncs, and releases the file lock through a new `File::unlock` (std `File::unlock` on Unix, `UnlockFileEx` on Windows, the Solaris `fcntl` release, the simulator's inode lock; a no-op default for memory and flash files). New transactions fail with the new `ErrorKind::Suspended` (C `EGGDB_ERR_SUSPENDED` = 24); a read transaction already open reads what the cache holds and fails on the first page it must read from the file.
- **Resume detects outside changes.** Before unlocking, the page file takes a CRC-32C fingerprint of both header slots, the file size and the log block where its next commit would go; `resume` re-locks (`Locked` while another program holds the file, retryable) and compares. Any difference marks the file failed with `NeedsReopen`, since the cache, free list and log position in memory are then stale; the app opens the database again. Reloading in place was rejected as a second, rarely-run recovery path.
- **Bindings.** `eggdb_suspend` and `eggdb_resume` in the C API, and `suspend()`/`resume()` plus the power source of D1087 on the Swift and Kotlin `KeyValue` classes, for `applicationDidEnterBackground`/`onStop` and their counterparts.
- **Clocks under Doze.** Timeouts use the monotonic clock, which stops during Android deep sleep, so a wait never expires just because the device slept; expiry times use the wall clock, so keys still expire on time after a sleep.

**Status:** code written, unbuilt (code-only mode, D355).
