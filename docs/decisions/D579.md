## D579 The by-query APIs apply the index's mappings — Decided by the code-only session (2026-11-12, D355); roadmap M8, D559

D559 applied mappings in `_search` and `_count` only, so `_update_by_query` and `_delete_by_query`
with `{"term": {"status.keyword": "open"}}` or a date `range` matched other documents than a
`_search` with the same query. Each index the by-query APIs walk now reads its own stored mappings
and rewrites the query with `mappings::apply` before matching, exactly as `_search` does, with
date math anchored when the walk starts. Indices are walked one at a time, so each uses its own
mappings rather than the first index's.
