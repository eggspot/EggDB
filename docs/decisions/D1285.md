## D1285 sqlite3 conveniences in the Python driver — Decided by the code-only session (2026-11-18, D355); roadmap M6 drivers (D16, D957, D1266)

- **What users get.** Code written for Python's `sqlite3` module finds more of what it uses: `Connection.executescript(script)` and `Cursor.executescript` (commit first, then every statement as written), `Connection.in_transaction`, `Connection.total_changes` and `Cursor.lastrowid` after an `INSERT`, in EggDB's SQLite dialect.
- **How.** `lastrowid` and `total_changes` ask the engine's own `last_insert_rowid()` and `total_changes()`, which the SQLite dialect answers as SQLite does; `lastrowid` asks only when read, so inserts cost nothing more. In other dialects `lastrowid` is `None` and `total_changes` is refused.
- **Left.** `row_factory` and `sqlite3.Row`, `create_aggregate` and `create_collation`, `iterdump` and `backup`.
- **Proof.** A Python test runs a script, reads an insert's rowid, the transaction state before and after a commit, the change count, and no rowid after a `SELECT`.
