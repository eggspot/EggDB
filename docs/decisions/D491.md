## D491 Per-agent time limits and quotas, and the agent's role in each MCP audit record — Decided by the code-only session (2026-11-11, D355); roadmap M6d, D190

- A line of `--mcp-token-file` may follow the token with options: `time_limit=<seconds>` (1–300,
  default 5) sets the call time limit of that agent's sessions, and `calls_per_minute=<n>` caps
  its `POST` calls in a fixed one-minute window; past it the endpoint answers 429 with a JSON-RPC
  error and `Retry-After` in seconds. An unknown option or a bad value stops `eggdb serve` with the
  line's number.
- Every `call` and `call_started` audit record carries `role` when the agent's token is tied to a
  stored role, and `eggdb audit`'s entries read it back (`AuditEntry::role`).
- Quotas count per token in the server's memory; a restart starts them over. Byte quotas and
  quotas for the stdio `eggdb mcp` are not written.
