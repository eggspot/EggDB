## D530 MongoDB `$text` — Decided by the code-only session (2026-11-11, D355); roadmap M9

`{$text: {$search: ..., $language, $caseSensitive, $diacriticSensitive}}` filters documents by
the fields of the collection's text index, as MongoDB does, where it was refused.

- **Index:** the collection must have a text index (a key with `"text"` values, or `$**`), else
  the query fails with code 27, `text index required for $text query`, MongoDB's error. The index
  is a definition only (D529's note applies): matching scans the collection.
- **Search string:** words, `-word` exclusions, `"quoted phrases"` and `-"excluded phrases"`.
  Words are folded to lower case (unless `$caseSensitive`), English stop words dropped and words
  stemmed with EggDB's Porter stemmer (D195) unless `$language` is `none`, on both sides.
- **Matching:** a document matches when every phrase appears in an indexed field (as text,
  case-folded unless case-sensitive), no excluded word appears, and, without phrases, at least
  one search word appears, MongoDB's rules. Fields are read through arrays and embedded
  documents.
- **Where it applies:** `find`, `update`, `delete`, `findAndModify` and `count`, the store paths
  that filter documents; `$text` must be at the top level of the filter (or in its top-level
  `$and`).
- **Left out:** `{$meta: "textScore"}` scores and sorting by them, `$text` in aggregation
  `$match`, other languages' stemmers, diacritic folding, and weights.

**Status:** code written, unbuilt (code-only mode, D355).
