## D1299 PostgreSQL's unistr — Decided by the code-only session (2026-11-18, D355); roadmap M4 PostgreSQL functions (D1296)

- **What users get.** PostgreSQL 14's `unistr(text)` in the PostgreSQL dialect, decoding `\XXXX`, `\+XXXXXX`, `\uXXXX` and `\UXXXXXXXX` escapes (characters beyond the Basic Multilingual Plane included) and `\\`, with an error for a short or invalid escape; Oracle's `UNISTR` (D1296) reads the same forms.
- **How.** D1296's decoder learned the three longer forms; `unistr` is answered in PostgreSQL's dialect beside Oracle's.
- **Left.** Nothing of its own.
- **Proof.** A unit test decodes all four forms in one string, an emoji among them.

**Status:** code written, unbuilt (code-only mode, D355).
