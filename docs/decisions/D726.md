## D726 GQL path modes: `WALK`, `TRAIL`, `ACYCLIC` and `SIMPLE` — Decided by the code-only session (2026-11-12, D355); roadmap M13, GQL quantified paths (D333, D535)

- A path pattern may start with a GQL path mode, with an optional `PATH` or `PATHS`, before or after a `SHORTEST`
  prefix: `MATCH p = ACYCLIC (a)-[:R]->{1,5}(b)`, `MATCH ANY SHORTEST SIMPLE PATH (a)-[:R]->+(b)`.
- `TRAIL` is the default and what Cypher always did: no relationship twice in a pattern. `WALK` lifts that, so a
  variable-length step may take a relationship again, within the hop bounds (at most 15 hops, D206) and the
  query's row budget. `ACYCLIC` also refuses a node twice; `SIMPLE` refuses a node twice except a path that ends
  where it started.
- `ACYCLIC` and `SIMPLE` are checked on each whole match, so they keep the path's relationships even when the
  pattern names no path variable. Shortest-path searches never revisit a node, so a mode does not change them.
- Still left then: quantified path patterns over several elements (one-relationship groups came with D727).
