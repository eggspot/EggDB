## D381 SQLite's `json_group_array` and `json_group_object` — Decided by the code-only session (2026-11-10, D355); roadmap M5, extends D378

In the SQLite dialect `json_group_array(X)` and `json_group_object(NAME, VALUE)` (with an optional
`ORDER BY` inside the parentheses) are PostgreSQL's `json_agg` and `json_object_agg`, which
EggDB already has, over the same values, with two SQLite touches: the result goes through
SQLite's `json()` (D378) so it is minified as SQLite writes it (`[1,null,3]`, not `[1, null,
3]`), and over no rows they give `[]` and `{}` instead of NULL. A NULL value is `null`, text is
a JSON string, and the result of a JSON function is placed as JSON (D378's `Value::Json`).
