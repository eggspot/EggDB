## D1238 SQLGetInfo's fixed answers in the ODBC driver — Decided by the code-only session (2026-11-17, D355); roadmap M6f, the ODBC driver (D968)

- **What users get.** `SQLGetInfo` answers about fifty more information types that driver managers and tools ask on connecting: identifier lengths (63 bytes, as EggDB's names), the schema, table and procedure terms, no catalogs, `\\` as the search pattern escape, transaction isolation options and the serializable default, cursor commit and rollback behaviour, forward-only scrolling, outer joins, multiple result sets, `NULL` collation, correlation names, SQL-92 entry and ODBC core conformance, the database name, and whether the data source was opened read-only. Unknown types are still `HY096`.
- **How.** A table of fixed answers (text, 16-bit or 32-bit), looked up after the connection-specific ones; the connection now remembers `ReadOnly`.
- **Left.** The function and conversion bitmasks (`SQL_STRING_FUNCTIONS`, `SQL_CONVERT_*`), `SQL_KEYWORDS`, the user name (empty for an embedded file), and server connections.
- **Proof.** The ODBC integration test reads a 16-bit answer, a term, the read-only flag and an unknown type's error.

**Status:** code written, unbuilt (code-only mode, D355).
