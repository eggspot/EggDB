## D816 MySQL and TDS logins in the audit log — Decided by the code-only session (2026-11-12, D355); follow-up of D815

- The MySQL listener reports each login to `eggdb_sql::audit_events::record_login`, accepted or refused, with the
  client's address and the plugin that checked it (`caching_sha2_password`, or `mysql_native_password`, the switch
  included). The TDS listener does the same with the method `sql-login` once the password is checked (a login for
  another user than the served one counts as refused, as the listener answers it).
- With D815, `EGGDB_AUDIT=1` now records logins from all three SQL protocols. Logins to the other listeners (RESP,
  MongoDB, AMQP, MQTT, NATS, Kafka, CQL, HTTP) are left, with reads of chosen tables.
