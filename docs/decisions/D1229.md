## D1229 Subqueries in SQL Server's showplan — Decided by the code-only session (2026-11-17, D355); roadmap M6c, subqueries in the tabular plans (D327)

- **What users get.** `SET SHOWPLAN_TEXT ON`, `SHOWPLAN_ALL` and `STATISTICS PROFILE` of a statement with subqueries show each one joined to the outer query as SQL Server draws them: a `WHERE` subquery under `Nested Loops(Left Semi Join)`, a select-list subquery under `Nested Loops(Left Outer Join)`, an aggregating subquery with `Stream Aggregate(Aggregate)` over its access, nested subqueries in turn.
- **How.** The SQL Server session plans with D327's subplans (`explain_with_subplans`), and the operator list puts one nested-loops join per subquery above the outer query's operators, outermost for the last subquery, with each subquery's operators as the join's second input.
- **Left.** `Left Anti Semi Join` for `NOT EXISTS` and `NOT IN` (D327's subplans don't record the negation), SQL Server's choice of hash or merge semijoins and row-count spools, and `Compute Scalar` rows.
- **Proof.** `dialect_plan_tests.rs`: an `EXISTS` subquery under a left semi join with both tables' scans, and a `COUNT(*)` subquery in the select list under a left outer join with a stream aggregate.
