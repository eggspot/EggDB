- **What users get.** `ALTER DATABASE d SET name {TO | =} value`, `SET name TO DEFAULT`, `RESET name` and `RESET ALL` give every session on the database its settings at login, beneath the per-role ones of D1313; `ALTER ROLE ALL SET` without a database now applies too, beneath everything else, as in PostgreSQL. `pg_catalog.pg_db_role_setting` lists every stored pair with `setdatabase` and `setrole` (0 for "all") and `setconfig` as `name=value` texts, which pgAdmin and `psql`'s `\drds` read.
