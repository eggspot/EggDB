## D915 HTTP foreign sources — Decided by the code-only session (2026-11-12, D355); roadmap M18, foreign sources, follow-up of D229

- `eggdb_foreign('http://host[:port]/path', '*')` (and so `eggdb_etl` copies) GETs the URL with EggDB's HTTP client
  and reads the body by its path: `.csv` as CSV (as `file:` sources), `.parquet` as Parquet, anything else as a JSON
  array of objects, each object one row. A response other than 200, a body over 1 GiB, or a JSON value that is not
  an array of objects is an error. `https://` waits for the HTTP client's TLS.
- An `EGGDB_FOREIGN_SOURCES` entry `http://host[:port]/prefix/` allows the URLs on that host and port whose path
  continues the prefix after a `/`; a path with `.` or `..` segments is refused. Without such an entry SQL reaches no
  URL, so a statement cannot make the server fetch arbitrary addresses.
