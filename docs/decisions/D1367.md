## D1367 Memory-only collections in the engine — Decided by the code-only session (2026-11-25, D355); roadmap M7 "Memory-only collections in the engine, with expiry and eviction" (D2, D193)

- **What users get.** `Database::create_memory_collection(name, limit_bytes)` makes a named key space that lives in the process only: `get`, `put` with an optional time to live, `delete`, `time_to_live`, `len`, `bytes`, `evicted` and `remove_expired` on the returned `MemoryCollection`. Its keys never cost a page write or a log record and are gone when the database closes, which is what a cache wants. With a byte limit, a put that takes the collection past it evicts the least recently used keys (Redis's `allkeys-lru`), never the key just written; a key and value larger than the whole limit fail with `TooLarge`.
- **Why beside, not inside, the file's collections.** A file collection's keys go through the B-tree, the log and the transaction system; keeping a flag per collection that diverts its keys to memory would put a second storage path under every read, scan and commit, and transactions spanning both would promise an atomicity the memory side cannot keep across a crash. A separate API says plainly what survives and what does not. One name never means two key spaces: a name a file collection has is refused.
- **How.** Each collection keeps a hash map of entries and a map from a use counter to the key, so the least recently used key is found in logarithmic time; expired keys are removed when read, and `remove_expired` sweeps them all. Times come from the platform's monotonic clock, so a change of the wall clock does not expire keys.
- **Left.** Reaching memory collections from SQL, the CLI and `eggdb serve`'s RESP and memcached listeners (which keep their own memory budget and eviction, D193, today), eviction policies other than LRU (LFU, volatile-only), and statistics in `collection_stats`.
- **Proof.** A unit test fills a collection to its limit, sees a zero time to live read as absent, evicts the least recently used key after another was read, refuses a value larger than the limit, and reports times to live and deletes.

**Status:** code written, unbuilt (code-only mode, D355).
