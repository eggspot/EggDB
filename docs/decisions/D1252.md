## D1252 Oracle's DBMS_ROWID — Decided by the code-only session (2026-11-18, D355); roadmap M10, Oracle's `ROWID` (D1233, D1251)

- **What users get.** In the Oracle dialect, `DBMS_ROWID.ROWID_OBJECT`, `ROWID_RELATIVE_FNO`, `ROWID_BLOCK_NUMBER`, `ROWID_ROW_NUMBER` and `ROWID_TYPE` read the parts of an 18-character extended `ROWID`, as scripts that group rows by block or check which object a row is in use them. For EggDB's addresses (D1233) the object number is the table's OID, the file 1, and the block and row the same place `ctid` shows.
- **How.** Each part is the base-64 number of its digits in Oracle's `A-Za-z0-9+/` alphabet (six for the object, three for the file, six for the block, three for the row); `ROWID_TYPE` is 1, extended. A value that is not 18 characters of that alphabet raises ORA-01410 `invalid ROWID`; NULL gives NULL. `ROWID_BLOCK_NUMBER`'s optional second argument (the tablespace type) is accepted.
- **Left.** `ROWID_CREATE`, `ROWID_INFO` and `ROWID_TO_ABSOLUTE_FNO`, and restricted (version 0) rowids.
- **Proof.** A unit test reads the four parts and the type of one rowid, and refuses a short and a misspelt one.

**Status:** code written, unbuilt (code-only mode, D355).
