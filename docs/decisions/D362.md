## D362 Oracle's interval partitioning — Decided by the code-only session (2026-11-10, D355); extends D169 and D361's partition record version 3

Oracle's `PARTITION BY RANGE (c) INTERVAL (expr) (PARTITION ...)` creates a partition the first
time a row lands at or above the highest listed bound, the transition point. EggDB stores the
interval's Oracle text and the transition point on the partitioned table's record (version 3,
option `2`, after D361's options byte), so nothing about the existing partitions changes.

- **Creation.** The key must be one column (`ORA-14750`) of a range table, the listed partitions
  must end below `MAXVALUE` (`ORA-14761`), and `transition + interval` must evaluate to a value
  above the transition (`ORA-14752`), which checks that the interval is a constant of the key's
  type: a number for a number, `NUMTOYMINTERVAL` / `NUMTODSINTERVAL` / an interval literal for a
  date or timestamp. `STORE IN (...)` is accepted and ignored, as tablespaces are.
- **Insert.** When a row has no partition, the insert stops before writing anything, finds the
  smallest `k` with `transition + k * interval` above the key by doubling and then halving `k`
  (each step evaluates the expression, so months of different lengths are exact), creates
  `[transition + (k - 1) * interval, transition + k * interval)` as `SYS_P<n>` (the first `n` not
  taken), and routes the statement again. The partitions in between are not created, as in
  Oracle. A `NULL` key or a key below the transition is still `ORA-14400`; more than 1048575
  intervals is `ORA-14300`. Rows named into a `PARTITION (...)` never create one.
- **Maintenance.** `ADD PARTITION` is `ORA-14760`; the other `ALTER`s work on the created
  partitions as on any other.

**D35 review.** Covered by D361's version 3: a file with an interval table is refused by older
EggDB versions as a newer format; files without one are unchanged. Decoding checks that the
option sits on a one-column range key and that the transition is one value.

**Left:** an `UPDATE` moving a row above the transition (Oracle creates the partition then),
`ALTER TABLE ... SET INTERVAL`, Oracle's `SYSTEM` partition names in its dictionary views.
