## D630 Oracle MERGE PARTITIONS first TO last — Decided by the code-only session (2026-11-12, D355); roadmap M2, D169, D360

Oracle 12.2 lets `ALTER TABLE t MERGE PARTITIONS p1 TO p4 INTO PARTITION p` name a span of range
partitions by its first and last members instead of listing each one. D360 parsed only the list
form, so a span stopped at a syntax error.

- The parser reads `TO` after the first name and produces `AlterAction::MergePartitionSpan`.
- `partition_alter::range_span` orders the table's range partitions by their lower bound, takes
  every partition from the first to the last inclusive, and hands their names to the existing
  `merge`, which already checks adjacency and rebuilds the rows.
- A span whose first partition does not come before its last is refused with ORA-14274. A span
  over list or hash partitions is refused with ORA-14255: list partitions have no order of their
  own to span.
- Test: `oracle_merges_a_span_of_range_partitions`.
