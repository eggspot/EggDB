## D826 The authentication rule file on the TDS listener — Decided by the code-only session (2026-11-12, D355); roadmap M6b, D185

- The TDS listener applies `--auth-rules` to stored roles (`ServerConfig.auth_rules`) as the MySQL listener does
  (D825): LOGIN7 carries the password, so `scram-sha-256` checks it against the stored verifier (D824), and `ldap`,
  `jwt` and `apikey` check it with that method and then require a stored role with `LOGIN`; `cert` needs a TLS client
  certificate naming the user; `reject` and `oauth` refuse. Refusals answer error 18456.
- The password check of `ldap`, `jwt` and `apikey` moved into `eggdb-auth` as `AuthMethod::check_secret`, used by
  both listeners (the PostgreSQL listener keeps its own copy for now).
