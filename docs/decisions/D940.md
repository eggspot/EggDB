## D940 Key-value transactions and collections in the Dart package — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930 to D939

- `drivers/dart/lib/eggdb.dart` adds `KeyValue.open(path, readOnly:, library:)` (`begin(writing:)`, `read`, `write`
  committing when the function returns and rolling back when it throws, `close`) and `Transaction`, over the C API
  through `dart:ffi` like `Database`.
- A transaction has `get`/`getText`, `put`/`putText` (with a `Duration` time to live), `delete`, `scan` (named
  arguments for the range, prefix, reverse, end inclusive and a limit, returning `KeyValueEntry` values),
  `createCollection`, `dropCollection`, `renameCollection`, `collections()` and `collectionStats`; `collection: null`
  is the default key space. Every buffer the C API returns is copied into a `Uint8List` and freed at once.
- With it every official driver (Python, Go, Node.js, .NET, C++, Ruby, PHP, Java, Kotlin, Swift, Dart) offers the
  key-value API with collections, closing the drivers part of D292.
