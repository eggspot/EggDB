## D995 SQL Server's `@@DBTS` and `MIN_ACTIVE_ROWVERSION()` — Decided by the code-only session (2026-11-13, D355); roadmap M10, `rowversion` (D798)

- `@@DBTS` is the database's last rowversion drawn: the last value of D798's database-wide sequence
  `eggdb_internal.sqlserver_rowversion`, as 8 big-endian bytes, or `0x00000000000007D0` (2000, SQL Server's first
  value) before any row was stamped or when no table has a rowversion column.
- `MIN_ACTIVE_ROWVERSION()` is the next value after it. SQL Server answers the lowest value of a still-open
  transaction; EggDB's sequence values are drawn outside transactions (D798), so none is held back and the next value
  is the lowest one any transaction can still write, which is what callers use it for (change detection that never
  misses a row).
- Both read the sequence through a new internal function, `eggdb_sequence_last_used`, which loads sequences for the
  statement as `nextval` and `currval` do (the statement's tokens name `@@DBTS` or `MIN_ACTIVE_ROWVERSION`) and does
  not draw a value or need one drawn in the session.
