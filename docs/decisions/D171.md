## D171 Compressed values: our own LZ4-format block codec, overflow chains of layout 2, and an incompatible feature bit — Decided by the build loop (by judgement, 2026-10-31); refines D34, D35 and D88

Part 4.M2-5 asks for data stored compressed, with our own codecs. Pages have fixed places in the
file, so a compressed page would save nothing on disk without sparse files. Compressing large
values does save space, since the pages a value needs shrink with it.

- **The codec.** `compression::lz4` writes and reads the LZ4 block format from LZ4's public
  format description, in our own code. Compression is greedy, with a 64 Ki-entry hash table of
  4-byte sequences, matches of at least 4 bytes within 64 KiB, and the format's last five
  literal bytes. Decompression checks every length and offset against the block and against
  the expected size before it copies, refuses a size more than 256 times the block's, and
  returns errors, never panics. The tests are hand-written blocks with known output, round
  trips over text, noise, runs and short inputs, and 20,000 hostile blocks.
- **Where.** With `Options::compress_values(true)` (`ValueCompression::Lz4` on the page
  cache), a value of 4 KiB or more is compressed when that saves at least a sixteenth of it.
  It is stored as a 4-byte length and the block, on an overflow chain whose pages have layout
  2. Reads detect the layout, so no option is needed to read. The first compressed value sets
  the incompatible feature `COMPRESSED_VALUES`, so a release from before this one refuses the
  file at open instead of reporting damaged pages later. A value read as a stream
  (`get_reader`) is decompressed whole first, and values streamed in with `put_reader` are
  stored uncompressed.
- **Reviewed as a format change** (D35): a new layout number behind a new feature bit, as
  format.md asks for overflow layout changes.

Left: a stronger codec of the Zstandard class (entropy coding, from RFC 8878) for cold data,
compressing leaf pages and log records, and the CLI and `eggdb serve` options.
