## D968 An ODBC driver on the C API — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D12 and D46's ODBC item

- `crates/eggdb-odbc` builds `libeggdb_odbc` (`eggdb_odbc.dll`), an ODBC 3 driver that driver managers (unixODBC,
  iODBC, Windows' ODBC manager) load. It is Rust, but a thin layer over the public C API (`eggdb_open`,
  `eggdb_sql_open`, `eggdb_sql_execute_with_parameters`), so it holds no SQL or storage logic of its own (D16, D17),
  and every crossing carries a whole statement and its result batch, never one value.
- **Calls.** `SQLAllocHandle`/`SQLFreeHandle` for environments, connections and statements; `SQLSetEnvAttr` and
  `SQLGetEnvAttr` (the ODBC version); `SQLConnect` (the data source name read as the file's path) and
  `SQLDriverConnect` (`Database=`/`DBQ=`/`Data Source=`, `Dialect=`, `ReadOnly=`; SQLite's dialect unless given);
  `SQLDisconnect`; `SQLExecDirect`, `SQLPrepare`, `SQLExecute`, `SQLBindParameter`, `SQLNumParams`;
  `SQLNumResultCols`, `SQLDescribeCol`, `SQLColAttribute` (count, name, label, type, nullability); `SQLFetch`,
  `SQLBindCol`, `SQLGetData` (in pieces for long text and bytes, `01004` and `SQL_NO_DATA` as ODBC asks);
  `SQLRowCount`, `SQLCloseCursor`, `SQLFreeStmt`; `SQLEndTran`, `SQLSetConnectAttr`/`SQLGetConnectAttr`
  (autocommit, on by default as ODBC requires; off opens a block before the next statement); `SQLSetStmtAttr`
  (accepted); `SQLGetInfo` (driver and DBMS names and versions, ODBC version, quote character, transaction
  capability, `SQLGetData` extensions); `SQLGetDiagRec`.
- **Values.** Results are copied out of the C API's batch at once. C types: character, wide character, 16-, 32- and
  64-bit integers, float, double, bit, binary and default; bytes read as character come as hexadecimal, as ODBC
  converts binary to character. Column types are reported from the values (`SQL_BIGINT`, `SQL_DOUBLE`,
  `SQL_VARCHAR`, `SQL_VARBINARY`), since the C API carries values, not declared types. Binary parameters are inlined
  as `X'…'` literals, the form every dialect but PostgreSQL's reads, as the ADO.NET provider does.
- **Left.** `SQLTables`, `SQLColumns` and the other catalog functions, the `W` entry points (driver managers map ANSI
  drivers for Unicode applications meanwhile), the rest of `SQLGetInfo`, `postgresql://` and `mysql://` connections
  through `eggdb_sql_connect`, and the `odbcinst.ini` and installer entries.
- `tests/all/odbc.rs` drives a whole session through the exported functions: connect, create, prepare with bound
  parameters, row count, describe, fetch and get data (including a NULL), a rollback with autocommit off, and a
  diagnostic record for an error.
