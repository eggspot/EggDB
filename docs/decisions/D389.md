## D389 PostgreSQL's `IntervalStyle` output — Decided by the code-only session (2026-11-10, D355); roadmap M6a

`IntervalStyle` was kept and shown but intervals always printed in the `postgres` style. They now
print in the session's style wherever a value becomes text (`Value::to_text`), which covers query
results and casts to text, as PostgreSQL's `interval_out` does (`interval_style.rs`, following
PostgreSQL's `EncodeInterval`):

- `postgres_verbose`: `@ 1 year 2 mons -3 days 4 hours 5 mins 6.5 secs`; the first non-zero field
  decides the sign and a leading negative one becomes ` ago`; all zero is `@ 0`.
- `sql_standard`: `1-2` for year-month only, `3 4:05:06` for day-time only, a leading `-` when
  every field is negative, and `+1-0 -3 +0:00:00` with every sign written when the signs mix or
  both kinds of field are present; all zero is `0`.
- `iso_8601`: `P1Y2M3DT4H5M6.5S`, each field only when non-zero, negative fields signed, `PT0S`
  for zero.
- `postgres` is unchanged. Setting any other value is `22023` with PostgreSQL's list of values.

The style is read from the statement's settings (`pg_catalog::statement_settings`) when an
interval is printed. EggDB already reads all four styles as input. `DateStyle` output is still
ISO only.
