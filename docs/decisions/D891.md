## D891 SQL Server global temporary tables — Decided by the code-only session (2026-11-12, D355); roadmap M10, sql.md

- In the SQL Server dialect a table named `##name` is a global temporary table: an ordinary table every session sees
  and writes, unlike `#name`, which stays the session's own temporary table. `CREATE TABLE ##t` and `SELECT ... INTO
  ##t` record it in the session that made it, and `Session::close` drops it (`DROP TABLE IF EXISTS`, so one another
  session already dropped is skipped), as SQL Server drops it when its session ends.
- SQL Server waits for other sessions still using the table before dropping it; EggDB drops it at once when the
  creating session closes, and a statement another session is running at that moment keeps its own snapshot. A
  session that ends without `close` (a process killed) leaves its `##` tables behind until someone drops them.
