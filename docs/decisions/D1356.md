## D1356 Text-to-SQL as an MCP tool and a command — Decided by the code-only session (2026-11-25, D355); roadmap M6d "Text-to-SQL in every dialect through the MCP server (D31, D205)", the tool D779 left

- **What users get.** `eggdb question get <file> <endpoint> <model> <question> [--dialect <name>]` and its MCP twin `question_get` run `eggdb_ai.text_to_sql` (D779) on a read-only open and return its answer: the SQL, whether it was checked and any problem. Neither runs the query; an agent runs it with `run_sql`, whose read-only rules and confirmations apply (D121, D255), so a model's answer can never write by itself.
- **Name.** Tools take their command's words (D143), and `sql` already belongs to `run_sql` and `write_sql`, so the command is the noun `question` with the core verb `get`: it gets one value, the SQL for a question. The title says "Write SQL for a question".
- **Where the model is.** The endpoint and model are arguments, but the provider only posts to URL prefixes in `EGGDB_MODEL_ENDPOINTS` (D777), which `eggdb mcp` and `eggdb question` now read at start, so an agent cannot make the server call anywhere the user did not allow. The tool is `open_world`, as it reaches a service outside the database. API keys are not taken yet: local models (Ollama, vLLM, llama.cpp) need none, and keys from the secrets store need a sealing key the server does not hold.
- **Time.** A model may take longer than `eggdb mcp`'s default five-second limit, and a call past its limit ends the server (D121), so the description and the docs say to raise `--time-limit`.
- **Left.** API keys for hosted providers through MCP, schema retrieval for large schemas and few-shot examples (D779), and checking answers in the other dialects.
- **Proof.** The command model's parity test checks that on a database without `eggdb_ai` the command and the tool fail with the same `sql_error` code and category, and that an unknown dialect is `invalid_arguments`; the tools list counts 17 tools read-only and 29 with `--allow-write`.

**Status:** code written, unbuilt (code-only mode, D355).
