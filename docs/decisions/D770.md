## D770 Credentials per source, permission per role, and limits per call for eggdb_foreign — Decided by the code-only session (2026-11-12, D355); roadmap M18, credentials per source, permission per role, and a timeout and row limit per call (D229)

- **Permission per role.** `eggdb_foreign` no longer refuses every role but a superuser. The SQL layer passes the
  calling role (none for a superuser) to the program's reader in a new `ForeignRequest` (source, query, role), and a
  reader answers `ForeignFailure::Denied` (SQLSTATE 42501) or `Failed` (HV000). `eggdb sql` and `eggdb serve` let a
  role read a source only when an `EGGDB_FOREIGN_SOURCES` entry allowing that source ends in `#roles=` with the role
  (`+` between roles); a superuser reads every allowed source as before. The constraint context now carries the
  checked role's name instead of only whether one is checked.
- **Credentials per source.** `EGGDB_FOREIGN_PASSFILE` names a file in `.pgpass` format (host, port, database, user,
  password; `*` wildcards; backslash escapes; `#` comments; at most 1 MiB) read at each call, so each source has its
  own password without putting it in the URL or the shared `PGPASSWORD`/`SQLCMDPASSWORD`, which stay the fallbacks.
  Keeping the file readable only by the server's user is the operator's job.
- **Limits per call.** `EGGDB_FOREIGN_ROW_LIMIT` and `EGGDB_FOREIGN_TIMEOUT_SECONDS` stop a read past that many rows or
  seconds; both are checked as each row arrives, so a source that sends nothing is stopped by its connection's own
  timeouts or `statement_timeout`, not by this limit.
- Limits set per role or per source, and credentials held in the `eggdb_secrets` store (D751), are left.
