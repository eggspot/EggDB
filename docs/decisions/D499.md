## D499 The syslog sender's address as a column — Decided by the code-only session (2026-11-11, D355); roadmap M16, D315

- Each syslog row now has `sender text`: the IP address the datagram came from, or the TCP
  connection's peer address, as rsyslog's `fromhost-ip` reports it, so messages relayed without a
  hostname can still be told apart.
- The `syslog` table is created with the column; a table created before it (an older file) gets
  it the first time an insert fails, through `ALTER TABLE syslog ADD COLUMN IF NOT EXISTS sender
  text`, and the insert is tried again. A table changed in other ways is still refused and
  counted as before (D352).
- Syslog over TLS (RFC 5425) and beyond loopback, and rsyslog and syslog-ng in CI, stay open.

**Status:** code written, unbuilt (code-only mode, D355).
