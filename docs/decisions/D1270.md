## D1270 Flag aliases in the ispell template — Decided by the code-only session (2026-11-18, D355); roadmap M4 PostgreSQL text search (D1212, D1269)

- **What users get.** Hunspell dictionaries that compress their flags with `AF` aliases (most of LibreOffice's, which PostgreSQL's `ispell` template reads) work: the affix file's `AF n` header and its `AF flags` lines number the flag sets from 1, and a word listed as `word/2` holds the second set.
- **How.** The affix file's alias lines are kept in order; a dictionary word's flags, when aliases are defined, are read as the alias number and replaced by that alias's flags before they are split by the file's flag format. A number with no alias is an error naming the word.
- **Left.** Aliases on affix rules' continuation flags (dropped, as all continuation flags are), `AM` morphological aliases, compound words.
- **Proof.** A unit test reduces a cross-product form and a suffix form through aliases, leaves a form the alias does not allow, and refuses a word naming an undefined alias.

**Status:** code written, unbuilt (code-only mode, D355).
