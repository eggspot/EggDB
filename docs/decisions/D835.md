## D835 Nested Arrow columns — Decided by the code-only session (2026-11-12, D355); roadmap D240, Arrow IPC reading

- The Arrow reader (`eggdb-arrow`, so `read_arrow` and `eggdb import`) reads List, LargeList and Struct columns,
  nested to 32 levels, as text columns holding JSON: a list as an array, a struct as an object of its fields, a null
  list or struct as SQL NULL at the top and JSON `null` inside. Leaf values keep their meaning: numbers and booleans
  as JSON, text as strings, dates and timestamps as ISO 8601 text, decimals with their scale, binary as hex. Cast the
  column to `jsonb` to query inside it.
- Decoding follows the IPC layout: each nested level takes its field node and validity buffer (and a list its
  offsets buffer) in depth-first order, then its children. Offsets that run backwards, past their values or past the
  row limit are errors, never panics.
- Left: Map, Union, FixedSizeList, and dictionary-encoded values inside nested columns (refused by name).
