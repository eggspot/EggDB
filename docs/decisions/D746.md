## D746 Report rendering in CSV, HTML and PDF with filters — Decided by the code-only session (2026-11-12, D355); roadmap M11, interactive reports with filters and drill-down, in CSV, HTML and PDF (D46, D238)

- `eggdb_bi.render_report(name, format [, filters])` runs a report's query, keeps the rows whose columns (as text)
  equal each key of the `filters` object, and returns `bytea`:
  - `csv`: RFC 4180 with a heading row, every value quoted, NULL empty, CRLF line ends;
  - `html`: one `<table>` with a heading, values escaped;
  - `pdf`: through a new SQL function, `eggdb_pdf_table(title, rows)`, which lays a JSON array of objects out as a
    table on A4 pages in the standard Helvetica font (title on the first page, heading row on each page, long cells
    cut to their column, text outside Latin-1 shown as `?`), written as PDF 1.4 by EggDB's own code with no
    embedded fonts.
- Drilling down is passing the clicked row's values as filters to the next call; columns keep the query's order.
- Left: charts in the PDF and HTML, sending rendered reports by e-mail and to `https://` targets (the next item),
  and fonts beyond Latin-1.

**Status:** code written, unbuilt (code-only mode, D355).
