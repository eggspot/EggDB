## D1301 PostgreSQL's administration functions for dashboards — Decided by the code-only session (2026-11-18, D355); roadmap M4 PostgreSQL catalog compatibility (D12, D1294)

- **What users get.** In the PostgreSQL dialect: `pg_size_bytes('1.5 GB')` (bytes, B, kB, MB, GB, TB and PB in 1024s, PostgreSQL's errors and hint for a bad unit), `pg_column_size(value)` (fixed sizes for fixed types, the varlena header plus the bytes otherwise), and the answers of a server with no per-relation files, no JIT and nothing waiting on locks: `pg_relation_filepath`, `pg_relation_filenode`, `pg_column_compression` and `pg_current_logfile` give NULL, `pg_blocking_pids` and `pg_safe_snapshot_blocking_pids` an empty array, `pg_notification_queue_usage` 0, `pg_jit_available` false, `pg_reload_conf` true, `pg_my_temp_schema` 0 and `pg_is_other_temp_schema` false. pgAdmin's dashboard, Grafana's PostgreSQL panels and pg_activity call these and failed on the first one missing.
- **How.** A module answering in the PostgreSQL dialect only, in the evaluator's function chain and in typing.
- **Left.** `pg_trigger_depth` (which triggers use to stop recursion, so it must count real depth), `current_query`, `pg_listening_channels`, and the file functions (`pg_ls_dir`, `pg_read_file`, `pg_stat_file`), which EggDB does not offer.
- **Proof.** A unit test reads sizes with and without units and spaces, refuses a bad unit and a missing number, and sizes an integer and a short text.

**Status:** code written, unbuilt (code-only mode, D355).
