## D881 OGC API - Tiles with vector tiles — Decided by the code-only session (2026-11-12, D355); follow-up of D781, D520 and D608

- The OGC API on `--rest-listen` serves OGC API - Tiles (OGC 20-057) for its collections:
  - `/ogc/tileMatrixSets` and `/ogc/tileMatrixSets/WebMercatorQuad`, the one tile matrix set, in OGC 17-083r4's JSON
    with zoom levels 0 to 24 (256-pixel tiles, scale denominators from the standard 0.28 mm pixel);
  - `/ogc/collections/{id}/tiles`, the collection's vector tileset list, and `.../tiles/WebMercatorQuad`, the tileset
    with its layer's properties and a templated `{tileMatrix}/{tileRow}/{tileCol}` link;
  - `.../tiles/WebMercatorQuad/{z}/{row}/{col}`, the tile as a Mapbox Vector Tile (`application/vnd.mapbox-vector-tile`),
    built in one SQL statement the way pg_tileserv and Martin do: the features intersecting `ST_TileEnvelope`,
    transformed to EPSG 3857, clipped and scaled by `ST_AsMVTGeom` (extent 4096, buffer 64) and encoded by
    `ST_AsMVT` as one layer named after the collection, with the other columns as properties. An empty tile is a
    204; a tile outside the matrix is a 404.
- The landing page links the tile matrix sets, and conformance names Tiles' core, tileset, tilesets-list,
  geodata-tilesets and MVT classes.
- Left: other tile matrix sets (`WorldCRS84Quad` and the rest), map tiles (rendered images), GeoJSON tiles, tile
  caching, and the dataset-level tilesets combining collections.
