## D398 memcached's binary protocol — Decided by the code-only session (2026-11-10, D355); roadmap M7, extends D194

Some memcached clients (older Java and PHP ones, and those that need SASL) speak only the binary
protocol. EggDB's memcached listener now looks at a connection's first byte: `0x80`, the binary
request magic, switches the connection to the binary protocol (`binary.rs`); anything else stays
the text protocol of D194. Both run on the same item store and commands (`commands.rs`), so an
item written in one is read by the other.

- **Framing**: the 24-byte header (magic, opcode, key length, extras length, data type, vbucket,
  total body length, opaque, CAS), big-endian, with the opaque echoed and responses magic `0x81`.
  A key over 250 bytes, extras over 20 or a body shorter than its parts is `Invalid arguments`
  (`0x0004`) after the body is skipped; a value over 1 MiB is `Too large` (`0x0003`); a body the
  connection's memory budget cannot hold is `Out of memory` (`0x0082`).
- **Commands**: `Get`, `GetQ`, `GetK`, `GetKQ`, `Set`, `Add`, `Replace`, `Append`, `Prepend` and
  their quiet forms (a non-zero request CAS on `Set` compares, as `cas` does), `Delete(Q)`,
  `Increment(Q)`/`Decrement(Q)` with the delta, the initial value created when the key is missing
  and the expiration (`0xffffffff` means never create), `Flush(Q)`, `Touch`, `GAT(Q)`, `No-op`,
  `Version`, `Quit(Q)` and `Stat` (answered with the terminating empty stat). Status codes are
  memcached's (`Key not found`, `Key exists`, `Item not stored`, `Non-numeric value`, `Unknown
  command`).
- **Quiet commands** send nothing on success, and a quiet get nothing on a miss, so a batch ends
  with `No-op` as clients expect.
- **SASL**: `List mechanisms` answers `PLAIN`, and `Auth`/`Step` answer `Authenticated`, since the
  memcached listener takes no passwords (it serves loopback, as D194 says); checking a password
  comes with the listener's authentication.
- Responses carry the item's CAS (read back after a store), and a get's extras carry its flags.

**Status:** code written, unbuilt (code-only mode, D355).
