## D1255 ODBC escape sequences and the function bitmasks — Decided by the code-only session (2026-11-18, D355); roadmap M6 ODBC driver (D1236–D1240)

- **What users get.** Statements with ODBC's escape sequences run: `{d '2024-01-02'}`, `{t '...'}` and `{ts '...'}` literals, `{fn ...}` scalar functions, `{oj ...}` outer joins, `{escape '\'}` after `LIKE`, `{call p(...)}` and `{?= call f(...)}`, as Excel, Microsoft Query, Power BI and Crystal Reports write them. `SQLGetInfo` answers `SQL_STRING_FUNCTIONS`, `SQL_NUMERIC_FUNCTIONS`, `SQL_TIMEDATE_FUNCTIONS`, `SQL_SYSTEM_FUNCTIONS` and `SQL_CONVERT_FUNCTIONS` with exactly the functions the driver translates, so those tools offer them.
- **How.** The driver translates escapes outside quotes before it binds parameters, innermost first, into the connection's own SQL: the dialect named at connection decides the words (SQLite's `strftime`, `instr` and `date('now')`; MySQL's `concat` and `locate`; `EXTRACT`, `strpos` and `CURRENT_DATE` for PostgreSQL, Oracle and SQL Server). The functions: `CONCAT`, `LCASE`, `UCASE`, `LTRIM`, `RTRIM`, `LENGTH` (trailing blanks left out, as ODBC defines it), `CHAR_LENGTH`, `OCTET_LENGTH`, `SUBSTRING`, `LEFT`, `RIGHT`, `REPLACE`, two-argument `LOCATE`, `ASCII`, `CHAR`, `SPACE`; `ABS`, `CEILING`, `FLOOR`, `EXP`, `LOG`, `LOG10`, `MOD`, `POWER`, `ROUND`, `SIGN`, `SQRT`, `PI`; `NOW`, `CURDATE`, `CURTIME`, `CURRENT_DATE`, `CURRENT_TIME`, `CURRENT_TIMESTAMP`, `YEAR`, `MONTH`, `DAYOFMONTH`, `HOUR`, `MINUTE`, `SECOND`; `IFNULL`; and `CONVERT(x, SQL_type)` as a `CAST`. Another function name is passed through unchanged. An escape without its closing brace, or with a keyword ODBC does not define, fails with SQLSTATE 37000.
- **Left.** The `SQL_CONVERT_*` bitmasks, `SQLNativeSql`, `TIMESTAMPADD`/`TIMESTAMPDIFF`, the week and quarter functions, three-argument `LOCATE`, and `{fn USER()}`/`DATABASE()`.
- **Proof.** Unit tests translate every kind of escape for each family and refuse unclosed and unknown ones; the ODBC test runs a nested `{fn UCASE({fn CONCAT(...)})}`.

**Status:** code written, unbuilt (code-only mode, D355).
