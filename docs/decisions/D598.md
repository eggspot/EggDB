## D598 ON UPDATE CURRENT_TIMESTAMP in SHOW CREATE TABLE — Decided by the code-only session (2026-11-12, D355); roadmap M10, D416

D416 stamps MySQL's `ON UPDATE CURRENT_TIMESTAMP` columns and shows them in `information_schema`'s
`EXTRA`. `SHOW CREATE TABLE` left the clause out, so mysqldump and schema-diff tools such as
Skeema and Atlas lost it on a round trip.

- `ColumnSchema` gains `on_update_current_timestamp`, filled from the table definition's stamped
  columns (format 16, D416).
- MySQL's `SHOW CREATE TABLE` writes ` ON UPDATE CURRENT_TIMESTAMP` after the column's default,
  where MySQL puts it, and before its `COMMENT`.
- A test checks that a stamped column's line ends with the clause and that a plain one does not
  have it.
- Other dialects' table descriptions ignore the flag. Fractional precisions
  (`ON UPDATE CURRENT_TIMESTAMP(3)`) are written without the precision, as D416 keeps none.

**Status:** code written, unbuilt (code-only mode, D355).
