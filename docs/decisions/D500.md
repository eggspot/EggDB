## D500 MariaDB's `CREATE OR REPLACE SEQUENCE` — Decided by the code-only session (2026-11-11, D355); roadmap M10, extends D424

- In the MySQL dialect, `CREATE OR REPLACE SEQUENCE s ...` drops an existing sequence `s` and
  creates it with the new options in the same statement, as MariaDB does; with no sequence of that
  name it is a plain `CREATE SEQUENCE`. `OR REPLACE` with `IF NOT EXISTS` is refused, as MariaDB
  refuses it.
- `CreateSequence` carries `or_replace`; the drop uses the existing `DROP SEQUENCE IF EXISTS`
  path, so a sequence a column default still uses is refused the same way.
- Left: reading a sequence as a table (`SELECT * FROM s`) and `SHOW CREATE SEQUENCE`.
