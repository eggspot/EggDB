## D933 Key-value transactions and collections in the .NET driver — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930 to D932

- `EggDB.Data` gains `EggDbKeyValue` (opens an embedded file's key-value store) with `BeginRead()` and `BeginWrite()`,
  returning an `EggDbKeyTransaction` that is `IDisposable`: disposing it without `Commit()` rolls it back, the
  `using` shape ADO.NET transactions have.
- A transaction has `Get`, `Put` (a `TimeSpan` time to live), `Delete`, `Scan(EggDbScanOptions)` (range or prefix,
  reverse, end inclusive), `CreateCollection`, `DropCollection`, `RenameCollection`, `Collections()` and
  `CollectionStats(name)`; keys and values are `ReadOnlySpan<byte>` with `string` (UTF-8) overloads, and the
  collection argument is `null` for the default key space.
- The calls are source-generated `LibraryImport`s; spans are pinned with `fixed` for the call only, and every buffer
  the C API hands out is copied into managed memory and freed at once. `EggDB.Data.Check` exercises it.
