## D502 Reading a MariaDB sequence as a table — Decided by the code-only session (2026-11-11, D355); roadmap M10, extends D424

- In the MySQL dialect, `SELECT * FROM s` on a sequence answers MariaDB's one row:
  `next_not_cached_value` (the next value the sequence gives), `minimum_value`, `maximum_value`,
  `start_value`, `increment`, `cache_size`, `cycle_option` (0 or 1) and `cycle_count` (0, as EggDB
  keeps no count of wraps), instead of PostgreSQL's `last_value`, `log_cnt` and `is_called`, which
  other dialects keep. An identity column's implicit sequence keeps PostgreSQL's columns.
- This finishes the MariaDB sequences line (D424, D500, D501).
