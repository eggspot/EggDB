## D983 SQL text search dictionaries and configurations — Decided by the code-only session (2026-11-13, D355); roadmap M8, synonyms and stop words (D30, D195)

- `CREATE`, `ALTER` and `DROP TEXT SEARCH DICTIONARY` and `CONFIGURATION` run in the PostgreSQL dialect. A
  dictionary uses the `simple`, `snowball` or `synonym` template; a configuration starts as a copy of a built-in or
  defined one (`COPY =`) or empty (`PARSER = default`), and `ADD`, `ALTER` and `DROP MAPPING` give each token type
  its dictionaries. `ispell` and `thesaurus` are refused as not supported yet.
- Each word is given the default parser's token type (`asciiword`, `word`, `numword` or `uint`, EggDB's
  tokenizer splitting no hyphenated words, URLs or e-mail addresses), and the type's dictionaries are asked in turn:
  the first that knows the word gives its lexeme or drops it as a stop word; a word no dictionary knows is dropped,
  as in PostgreSQL. Built-in configurations copy as PostgreSQL's do: word types to `<language>_stem`, the others to
  `simple`.
- EggDB keeps no `tsearch_data` files (D3: one data directory, nothing beside it), so `StopWords` names a built-in
  language's list and `Synonyms` only PostgreSQL's `synonym_sample`; any other file name is refused with a message
  naming EggDB's own `StopWordList` and `SynonymList` options, which hold the words inline in the definition.
- The objects are stored in the SQL key space under a key space of their own (0x19), one record per dictionary
  and per configuration, versioned. A statement loads them only when its tokens call a text search function or
  `@@`, when a table it reads has defaults, checks, generated columns or a view query that call one, or when a
  routine's statement does, so other statements pay nothing. Built analyzers are kept for the statement.
- Names follow PostgreSQL: a configuration or dictionary may not take a built-in's name, a dictionary used by a
  mapping cannot be dropped (`2BP01`), and renaming a dictionary renames it in every mapping.
- `pg_dump` restores now run these statements instead of skipping them.
- Left: `ispell` and `thesaurus`, `CASCADE` on drop, `SET SCHEMA`, and the `pg_ts_*` catalog tables.
