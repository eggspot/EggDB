## D1140 TPC-C's transactions against PostgreSQL and MySQL — Decided by the code-only session (2026-11-14, D355); roadmap M5 (TPC-C against PostgreSQL and MySQL, D7)

- **What is measured.** `crates/eggdb-tpcc-compare`, outside the workspace and never shipped, as the other comparison
  crates are, loads the same TPC-C-shaped population into EggDB and into the other database and times the five
  transactions on both:
  - New-Order: district counter, order, new-order row, and five to fifteen lines with stock updates;
  - Payment: warehouse, district and customer totals and a history row;
  - Order-Status: the customer's latest order and its lines;
  - Delivery: the oldest new order of each district delivered and the customer credited;
  - Stock-Level: distinct items of the last twenty orders below a stock threshold, a join.

  Each is measured as EggDB's time per transaction over the other's, in pairs: EggDB over its PostgreSQL protocol
  against PostgreSQL 17, and over its MySQL protocol against MySQL 8.4, so each side runs its own dialect and wire
  path.
- **No third-party code.** The clients are EggDB's own (`eggdb_pgwire::client`, `eggdb_mysqlwire::client`). The
  population and parameters come from a fixed mixing function, so every run and both servers get the same work.
- **Size.** One warehouse, 300 customers per district and 10,000 items by default (`TPCC_WAREHOUSES`,
  `TPCC_CUSTOMERS`, `TPCC_ITEMS`), so CI's run fits in its 30 minutes. A larger run on dedicated hardware uses the
  same program.
- **CI.** The `tpcc-compare` job runs both databases as services beside `eggdb serve` and reports the ratios in the
  run's summary and artifacts. As with the other comparison jobs, only a result more than 2x its baseline line
  blocks (D101). The release steps in `CLAUDE.md` update its lock file with the wire crates it uses.
- **Not an audited TPC-C.** There are no terminals, keying or think times, the population is scaled down, and no
  response-time limits are checked. An audited run at full scale is the owner's decision on cost (Needs the owner).

**Status:** code written, unbuilt (code-only mode, D355).
