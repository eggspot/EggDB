## D877 An OData v4 service over the schema — Decided by the code-only session (2026-11-12, D355); roadmap M6a, D37

- `eggdb-api` serves the schema's tables as an OData v4 service under `/odata`, on the REST listener and with its
  sign-in, so Excel's and Power BI's OData feeds, SAP tools and other OData clients read and write EggDB tables.
  Every request runs as SQL in the signed-in user's session (roles and row security apply).
- `/odata/` is the service document; `/odata/$metadata` is CSDL XML with one `EntityType` and `EntitySet` per table
  in namespace `EggDB`, keys from primary keys (all columns for a table without one), and SQL types mapped to OData's
  primitives (`Edm.Int16/32/64`, `Edm.Decimal`, `Edm.Double`, `Edm.Single`, `Edm.Boolean`, `Edm.Date`,
  `Edm.DateTimeOffset` for both timestamp types, `Edm.TimeOfDay`, `Edm.Guid`, `Edm.Binary`, else `Edm.String`).
- `GET /odata/<set>` takes `$filter`, `$select`, `$orderby`, `$top`, `$skip` and `$count=true`. `$filter` is read by
  our own parser of OData's expression grammar (`or`, `and`, `not`, `eq` ... `le`, `in`, `add` ... `mod`, unary
  minus, parentheses, string, number, date and time literals, `null`, `true`, `false`, and the functions `contains`,
  `startswith`, `endswith`, `length`, `indexof`, `substring`, `tolower`, `toupper`, `trim`, `concat`, `year` ...
  `second`, `date`, `round`, `floor`, `ceiling`, `now`) and turned into SQL with quoted identifiers of known
  properties and quoted literals; `eq null` and `ne null` become `IS NULL` and `IS NOT NULL`. Results are ordered by
  the key unless `$orderby` says otherwise, and pages hold at most 10,000 entities, with `@odata.nextLink` carrying
  `$skip` (server-driven paging, which Power BI follows).
- `/odata/<set>(<key>)` (a single value, or `name=value,...` for composite keys) reads one entity (404 when none), and
  `/odata/<set>(<key>)/<property>` and `.../$value` read one property; `/odata/<set>/$count` is the count as plain
  text. `POST` to a set inserts (201 with the entity and `Location`), `PATCH`, `PUT` and `MERGE` on an entity update the
  properties sent (`PUT` does not reset the others yet), and `DELETE` removes it (204, or 404 when no row matched).
- Answers carry `OData-Version: 4.0` and `odata.metadata=minimal` JSON; timestamps are written as ISO 8601 with `T`
  and `Z` or an `hh:mm` offset; errors use OData's `{"error":{"code","message"}}`.
- Left: `$expand` and navigation properties (refused with 501), `$search`, `$apply`, batch requests, `PUT`'s full
  replacement, `$format=xml` and Atom, and the IEEE754Compatible number format.
