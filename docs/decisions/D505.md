## D505 NDJSON import and export — Decided by the code-only session (2026-11-11, D355); roadmap M11, D29

- `eggdb import <file> --ndjson <in> --table <name>` loads a file of one JSON object per line
  (blank lines skipped) into a table, created when missing: columns in the order keys first
  appear, each typed from every value it holds (`bigint` for integers, `double precision` when a
  decimal appears, `boolean`, else `text`; nested objects and arrays keep their JSON text), a key
  missing from a line being `NULL`. It loads in one transaction through the same path as
  `--parquet` (D202), at most 4 GiB and 1,600 keys.
- `eggdb export <file> --ndjson <out> --table <name>` writes the table's rows as NDJSON, one object
  per row with every column (dates and timestamps as text, non-finite floats as strings,
  `bytea` as `\x…` text).
- ORC and Avro are not written.
