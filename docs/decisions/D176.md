## D176 One-line installers that check the release's checksums, run and timed in CI — Decided by the build loop (by judgement, 2026-10-31); refines D14 and D75

Part 4.M4-2 asks for installing with one command and measuring it.

- **`scripts/install/install.sh`** (POSIX `sh`, with `curl` or `wget`) reads the latest release
  from GitHub's API, or `EGGDB_VERSION`. It picks the archive for the system: the static musl
  build on Linux (D75), the Apple build on macOS, on x86-64 or ARM64. It checks the archive's
  SHA-256 against the release's `SHA256SUMS`, then puts `eggdb` in `EGGDB_INSTALL_DIR`
  (`~/.local/bin` by default) through a rename, so a running `eggdb` is never half-replaced.
- **`scripts/install/install.ps1`** does the same on Windows with the zip archive, into
  `%LOCALAPPDATA%\EggDB\bin`, and adds that folder to the user's PATH.
- **Measured.** CI's `installers` job runs both on Linux, macOS and Windows against the latest
  release, and writes the seconds for download plus install and for the first start to the run's
  summary. Download size is the archive size in the release.

Left: package managers (Homebrew, winget, apt), which need accounts the owner sets up.
