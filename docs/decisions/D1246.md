## D1246 EggDB's own GORM dialector — Decided by the code-only session (2026-11-17, D355); roadmap M6f, the GORM dialect (D16, D182, D962)

- **What users get.** `eggdbgorm.Open(dsn)` (and `eggdbgorm.New`) now returns EggDB's own `gorm.Dialector`, so a Go program using GORM on EggDB no longer links SQLite through cgo (`gorm.io/driver/sqlite` and `github.com/mattn/go-sqlite3` are gone from the module's dependencies). Models migrate, create (ids from `RETURNING`), query, update and delete as before; `TranslateError` turns EggDB's unique and foreign key violations (SQLSTATE 23505, 23503) into `gorm.ErrDuplicatedKey` and `gorm.ErrForeignKeyViolated`; savepoints work; an `Offset` without a `Limit` writes SQLite's `LIMIT -1 OFFSET n`.
- **How.** The dialector names itself `sqlite`, as GORM and its plugins choose SQL forms by that name and EggDB speaks SQLite's SQL, registers GORM's callbacks with `RETURNING` for inserts, updates and deletes, opens the `eggdb` database/sql driver, maps GORM's field types to SQLite's type names (an auto-increment integer as `integer PRIMARY KEY AUTOINCREMENT`, so GORM adds no second primary key) and quotes names in backticks. Its migrator is GORM's generic one with the catalog reads replaced by EggDB's SQLite catalog: `sqlite_master` for tables and indexes, `PRAGMA table_info` for columns, `DROP INDEX` without a table, and an index renamed by recreating it from its stored SQL.
- **Decided by research.** GORM's SQLite dialector recreates a table to alter a column, because SQLite cannot alter one; EggDB can, so the generic migrator's `ALTER TABLE ... ALTER COLUMN` path is used instead, which is the behaviour EggDB's SQLite dialect accepts.
- **Left.** The sqlc check, `ColumnTypes` details beyond GORM's generic reading (`COLUMN_DEFAULT`, unique flags), and views and constraints in the migrator.
- **Proof.** `eggdbgorm_test.go`: the existing model round trip, and a new test of `HasTable`, `HasColumn` and `HasIndex`, a second `AutoMigrate` changing nothing, a duplicate translated to `gorm.ErrDuplicatedKey`, and an offset without a limit.
