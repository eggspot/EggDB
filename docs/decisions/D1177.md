## D1177 A gRPC API generated from the schema — Decided by the code-only session (2026-11-15, D355); roadmap M6a (generated APIs, D37)

- `eggdb serve --grpc-listen <address>` (default port 50051) serves, over EggDB's own HTTP/2 and gRPC framing (`eggdb-http2`, as Arrow Flight SQL does), one service per table of the REST listener's schema: `eggdb.v1.<Table>Service`, the table's name in PascalCase.
- Messages are generated from the columns: `<Table>` has one `optional` field per column, numbered by the column's position, so a NULL is an absent field; `<Table>Key` holds the primary key's fields with the same numbers; `<Table>ListRequest` has `limit`, `offset`, `order_by` (column names, `-` for descending) and `where` (a `<Table>` whose present fields are equality conditions). Types map to proto3 scalars: `smallint` and `integer` to `int32`, `bigint` to `int64`, `real` to `float`, `double precision` to `double`, `boolean` to `bool`, `bytea` to `bytes`, and every other type to `string` in PostgreSQL's text form, which keeps `numeric`, dates, times, UUIDs and JSON exact.
- Methods: `List` (server streaming, at most 100 000 rows a call, key order unless `order_by` says otherwise), `Get`, `Insert` (returns the stored row, defaults filled), `Update` (key fields find the row, other present fields are set) and `Delete` (returns `DeleteResult.deleted`). Each call is one SQL statement in the caller's session, with literals for every value, so row security, column privileges and triggers apply.
- Sign-in takes the REST API's `authorization` metadata (basic, or a bearer token under `--auth-rules`); a refused caller gets `UNAUTHENTICATED`. SQL errors map to gRPC codes: `42501` to `PERMISSION_DENIED`, constraint violations to `FAILED_PRECONDITION`, other `42`/`22` errors to `INVALID_ARGUMENT`, the rest to `INTERNAL`; a missing row is `NOT_FOUND`, an unknown service or method `UNIMPLEMENTED`.
- The `.proto` file is served at `GET /grpc/eggdb.proto` on the REST listener, for `protoc`, `grpcurl -proto` and client generators. Tables or columns whose names are not proto identifiers are left out of the API, rather than renamed.
- Not yet: server reflection (`grpc.reflection.v1`), which is a bidirectional stream and needs `eggdb-http2` to answer before a request body ends; client streaming for bulk inserts; filters other than equality.
- Test: `grpc_serves_each_table_as_a_service` in `eggdb-api`.
