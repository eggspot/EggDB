## D691 MySQL UpdateXML — Decided by the code-only session (2026-11-12, D355); roadmap M10, MySQL's XML functions (D690)

- `UpdateXML(xml, xpath, new_xml)` replaces the one element the XPath expression (D690) matches with `new_xml`, in
  the original text: the parser now keeps each element's byte span, so the rest of the document keeps its exact
  formatting, as MySQL's does.
- As in MySQL, when the expression matches no element, several, or something that is not an element (text, an
  attribute, a number), the XML comes back unchanged; a `NULL` argument gives `NULL`; and `new_xml` is put in as
  written, not checked.
