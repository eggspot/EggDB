## D934 Key-value transactions and collections in the C++ header — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930 to D933

- `eggdb.hpp` gains `eggdb::key_value` (`open(path, read_only)`, `read()`, `write()`) and `eggdb::transaction`,
  move-only RAII types: a transaction destroyed without `commit()` rolls back and a store closes its file.
- A transaction has `get` (an `std::optional<bytes>`), `put` (with `ttl_ms`), `erase`, `scan(scan_options)` (range,
  prefix, reverse, end inclusive), `create_collection`, `drop_collection`, `rename_collection`, `collections()` and
  `stats(name)`; `collection` is a C string, `nullptr` for the default key space; `eggdb::to_bytes` turns text into
  bytes. Buffers from the C API are copied and freed at once; errors throw `eggdb::error` as the SQL calls do.
