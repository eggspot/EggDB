## D1070 ISO 20022 schema validation — Decided by the code-only session (2026-11-13, D355); roadmap M16 (D50, D699)

- `iso20022_validate(message, schema) → jsonb` checks an XML message against the XML Schema (XSD) the
  ISO 20022 registry publishes for its message definition. The caller gives the schema; it is not shipped.
  The answer is `{"valid": bool, "issues": [{"path", "message"}]}`, at most 1,000 issues, each path such as
  `/Document/GrpHdr/Amt[1]/@Ccy`.
- The validator (`crates/eggdb-sql/src/xsd.rs`) reads the part of XSD that ISO 20022 schemas use. Any
  schema written in that part can be checked, not only ISO 20022:
  - global and local elements with `minOccurs` and `maxOccurs`;
  - named and anonymous complex types with `sequence`, `choice` and `all`, matched greedily (XSD's
    unique-particle rule makes that exact);
  - `simpleContent` extensions with attributes (amounts with a currency), `complexContent` extensions;
  - required, typed and undeclared attributes, and text where only elements may be;
  - simple types restricted by `enumeration`, `pattern` (anchored, through EggDB's own regular expression
    engine with a step budget), the three length facets, `totalDigits`, `fractionDigits` and the four
    bounds, along the whole restriction chain;
  - the lexical forms of the built-in types: decimals, the integer family, booleans, dates, dateTimes,
    times, gYear, gYearMonth and base64.
- A type used but never defined makes the schema unreadable (an error, not a pass). Nesting is limited
  to 128 levels.
- `xml_path::Document` gained read-only accessors (child elements, names, attributes, text) that the
  dictionaries (D1069) and this validator share.
- Left: lists, unions, wildcard contents, identity constraints (`key`, `keyref`), `import` and `include`
  across files, attributes inherited through `complexContent`, and DICOM conformance against IOD
  modules.
- Learned from: W3C XML Schema 1.0 parts 1 and 2, and ISO 20022's published message schemas as
  examples. No validator source was read.
