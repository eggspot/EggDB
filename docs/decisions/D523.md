## D523 SQL Server Agent jobs on the job scheduler — Decided by the code-only session (2026-11-11, D355); roadmap M10

The SQL Server dialect answers `msdb`'s Agent procedures, by `EXEC` with named or positional
arguments, and `eggdb serve`'s job thread runs the jobs on their schedules, as it runs pg_cron
jobs (D200) and MySQL events (D421).

- **Procedures:** `sp_add_job`, `sp_update_job` (`@enabled`, `@new_name`), `sp_delete_job`,
  `sp_add_jobstep` (TSQL steps, `@step_id` defaulting to the next, `@database_name` to the
  current database), `sp_add_schedule`, `sp_attach_schedule`, `sp_detach_schedule`,
  `sp_delete_schedule`, `sp_add_jobschedule` (add and attach in one), `sp_add_jobserver`
  (accepted, there is one server) and `sp_start_job` (runs the job's steps now, before
  answering, where SQL Server starts it in the background). Errors use SQL Server's numbers:
  14261 already exists, 14262 does not exist, 201 a required parameter missing, 8144 too many
  arguments, 8145 an unknown parameter, 14266 an unsupported value. Jobs and schedules are named,
  not addressed by `@job_id` or `@schedule_id`.
- **Storage:** internal tables in `eggdb_internal` (jobs, steps, schedules, attachments, history),
  as MySQL events are kept (D421), so the file format is unchanged.
- **Schedules:** `@freq_type` once (1), daily (4, every `@freq_interval` days), weekly (8, the
  `@freq_interval` day bitmask every `@freq_recurrence_factor` weeks) and monthly (16, on day
  `@freq_interval`); within a day at `@active_start_time`, or every `@freq_subday_interval`
  minutes (4) or hours (8) between the start and end times, within the start and end dates.
  Times are UTC, where SQL Server uses the server's local time. Monthly-relative (32), on Agent
  start (64), when idle (128) and every few seconds are refused.
- **Running:** each step runs in a SQL Server session in its database, in order, stopping at the
  first failure (SQL Server's default `@on_fail_action`), each outcome recorded in the history
  table with SQL Server's `run_status` (1 succeeded, 0 failed). The scheduler ticks once a
  minute.
- **Left out:** `msdb.dbo.sysjobs`, `sysjobhistory` and the other views, step flow options
  (`@on_success_action`, retries), operators and alerts, proxies, and non-TSQL subsystems.

**Status:** code written, unbuilt (code-only mode, D355).
