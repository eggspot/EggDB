## D931 Key-value transactions and collections in the Go driver — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930

- `eggdb.OpenKeyValue(path, readOnly)` opens an embedded file's key-value store through cgo on the C API, beside the
  `database/sql` driver. `Read`/`Write` begin a `*Txn`; `View` and `Update` run a function in one, `Update`
  committing when it returns nil and rolling back on an error, the shape Go's embedded stores use.
- A `Txn` has `Get`, `Put` (a `time.Duration` above zero sets a time to live), `Delete`, `Scan` (a `ScanOptions`
  range or `Prefix`, `Reverse`, `EndInclusive`, visiting entries until the callback returns false),
  `CreateCollection`, `DropCollection`, `RenameCollection`, `Collections` and `Stats`. The collection is the first
  argument; `""` is the default key space. Every buffer the C API hands out is copied into Go memory and freed at
  once, and every C string and key copy the driver makes is freed when the call returns.
