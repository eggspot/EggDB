## D704 read_csv — Decided by the code-only session (2026-11-12, D355); roadmap M11, the file readers in SQL (D29, D703)

- `read_csv(path) AS t(name type, ...)` (PostgreSQL dialect) reads a CSV file through the session's file reader
  (D703: embedded sessions read local files, servers none) and returns one row per record after the header.
- The first line names the columns and picks the delimiter: whichever of `,`, `;`, tab and `|` it holds most. Fields
  follow RFC 4180: double quotes around a field, `""` for a quote inside one, delimiters and line breaks inside
  quotes, `CRLF` or `LF` line ends, and a UTF-8 byte order mark ignored. An empty unquoted field is `NULL` and `""` is
  the empty string, as `COPY ... CSV` reads them.
- Each declared column takes the file's column with that name, ignoring case, or `NULL` when there is none, and its
  text is cast to the declared type. A file must be UTF-8 and at most 1 GiB; an unterminated quote is `22P04`.
- Left: options (header off, delimiter, quote and null strings), and typing columns from the file without a
  definition list.
