## D676 More InfluxQL: GROUP BY *, SLIMIT and SOFFSET, several measurements and distinct() — Decided by the code-only session (2026-11-12, D355); roadmap M16, InfluxQL (D220, D521, D675)

- `FROM` takes a comma-separated list of measurements and regular expressions (`FROM cpu, /^mem/`). Each regular
  expression is matched against the measurement tables by the SQL engine's `~` operator, so InfluxQL patterns get
  the same regular expression dialect as `WHERE tag =~ /.../`. The query runs once per measurement, in the listed
  order with each pattern's matches in name order and duplicates dropped, and each measurement's series are
  returned under its own name.
- `GROUP BY *` groups by every `text` column of the measurement. As D521 records, the store keeps tags and string
  fields alike as `text`, so string fields are grouped by too.
- `SLIMIT n` and `SOFFSET n` limit and skip whole series after they are made, instead of being read and ignored.
- `distinct(field)` returns one row per distinct value in each bucket (or at time 0 without `GROUP BY time()`), as
  a column named `distinct`. As in InfluxDB, it cannot be combined with other fields or functions, and no empty
  buckets are filled for it.
