## D1052 The etcd v3 API in eggdb-etcd — Decided by the code-only session (2026-11-13, D355); roadmap M15 (D54, D247)

- D742 left the etcd v3 API until EggDB had HTTP/2 and gRPC; `eggdb-http2` now has both. `eggdb-etcd` serves the API
  from etcd's published API reference and protocol buffer descriptions, over that transport, with every request one
  transaction of an EggDB keyspace (the `etcd` collections of the served file), like the ZooKeeper server.
- **Data model.** One store-wide revision (1 when empty) rises once per write request, however many keys it changes.
  Each key keeps its create and modify revisions, version and lease. Every change is logged under its revision and a
  sub-index, which serves ranges at a past revision and watches from a start revision; `Compact` drops the log below a
  revision and keeps, at their own revisions, the versions live at that point, so reads at and after the compaction
  still see every key, and reads before it get etcd's "required revision has been compacted" (`OUT_OF_RANGE`).
- **Services.** `KV` (`Range` with `range_end` meaning one key, a range, or every key from `key` on; limit, keys only,
  count only and revision; `Put` with lease, previous value, ignore value and ignore lease; `DeleteRange`; `Txn` with
  comparisons of version, create revision, modify revision, value and lease over a key or a range, and nested
  transactions up to eight deep; `Compact`), `Lease` (grant with or without an id, revoke, keep-alive, time to live
  with the attached keys, list), `Maintenance/Status` and `Cluster/MemberList`. Leases that passed their deadline are
  revoked, with their keys deleted, at the start of the next write.
- **Watch, limited.** EggDB's HTTP/2 server answers a request once its body has arrived, so a watch stream cannot stay
  open: `Watch` answers each create request with its "created" response and the history since its start revision, then
  ends the stream. etcd clients reconnect from the last revision they saw, which is how they already recover from a
  broken watch. Kept-open streams need a streaming server, which is left.
- **No authentication yet**, so `--etcd-listen` takes only a loopback address, as `--zookeeper-listen` does.
- `GrpcStatus` gains `FAILED_PRECONDITION` and `OUT_OF_RANGE`.
- etcd is a trademark of The Linux Foundation; EggDB is compatible with its v3 API. Learned from etcd's API reference
  and `rpc.proto`/`kv.proto` descriptions; no code was read.
