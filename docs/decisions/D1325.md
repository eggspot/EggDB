## D1325 A connection pool in the C API — Decided by the code-only session (2026-11-25, D355); roadmap M6f network drivers (D192, D293)

- **What users get.** Every driver over the C API can pool its server connections: `eggdb_pool_open(url, max_connections, &pool)`, `eggdb_pool_acquire(pool, timeout_ms, &sql)`, `eggdb_pool_release(pool, sql)`, `eggdb_pool_stats(pool, &open, &idle)` and `eggdb_pool_close(pool)`. The pool opens one session at once, so configuration errors show at startup, and more as borrowers need them up to its maximum; a borrower waits for a returned session up to its timeout, then gets `EGGDB_ERR_IN_USE`. Returning a session rolls back a transaction it left open, so the next borrower starts clean, and a session whose connection broke is closed instead of handed out again. Sessions lent by the pool are ordinary `eggdb_sql` handles for every other call.
- **How.** The pool keeps the idle and lent sessions' handles behind a mutex with a condition variable for waiters; it connects outside the lock, so a slow connect does not stop other threads from returning sessions. `eggdb_sql_connect`'s body became a function both share. A session with prepared statements or `COPY` handles still open cannot be returned, as it cannot be closed (D293).
- **Why in the C API.** D16 keeps protocol logic out of the per-language drivers; a pool that resets sessions needs to know the session's state, which only the C API does. Drivers whose language has a standard pool interface (ADO.NET's, JDBC's `DataSource`) wrap these calls.
- **Left.** Binary result formats over `eggdb_sql_connect`, health checks of idle sessions, an idle timeout, and the drivers' own pool settings in their connection strings.
- **Proof.** A remote test opens a pool of two, leaves a transaction open on one session and gets it back rolled back, is refused a third session within 20 ms, refuses a session the pool did not lend and closing while sessions are lent, and closes once both are back.

**Status:** code written, unbuilt (code-only mode, D355).
