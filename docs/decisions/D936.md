## D936 Key-value transactions and collections in the PHP driver — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930 to D935

- `drivers/php/src/KeyValue.php` and `Transaction.php` add `EggDB\KeyValue` (`new KeyValue($path, readOnly: ...)`,
  `read(callable)`, `write(callable)`, `begin(bool)`, `close()`) and `EggDB\Transaction`, over the C API through PHP's
  FFI like `Connection`.
- `write` commits when the callable returns and rolls back when it throws, returning its value; `read` always rolls
  back.
- A transaction has `get`, `put` (with `ttlMs`), `delete`, `scan` (a generator of key => value over a range or a
  prefix, reverse, end inclusive), `createCollection`, `dropCollection`, `renameCollection`, `collections` and
  `collectionStats`; `$collection` is `null` for the default key space. Keys and values are PHP strings passed as
  `const char *` with their length, so binary bytes go through unchanged; a key made only of digits becomes an
  integer key when a caller turns the generator into an array, as PHP does with every array.
