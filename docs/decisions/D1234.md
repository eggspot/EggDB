## D1234 DBMS_METADATA.GET_DDL for indexes and sequences — Decided by the code-only session (2026-11-17, D355); roadmap M10, Oracle's packages (D859)

- **What users get.** `DBMS_METADATA.GET_DDL('INDEX', name)` gives `CREATE [UNIQUE] INDEX "NAME" ON "TABLE" ("COL", ...);` for a secondary index or a primary key's index, and `GET_DDL('SEQUENCE', name)` gives `CREATE SEQUENCE "NAME" MINVALUE ... MAXVALUE ... INCREMENT BY ... START WITH ... CACHE n | NOCACHE CYCLE | NOCYCLE;`, with `START WITH` at the next value the sequence would give, as Oracle writes it, so a schema can be copied by script. A name of another kind is ORA-31603, as for tables and views (D859).
- **How.** The catalog snapshot already lists indexes and sequences as relations; `get_ddl` writes them from the index's table definition (its columns by position) and the stored sequence definition.
- **Left.** Oracle's storage clauses and quoted owner prefixes, descending and function-based index columns, and the other object types (triggers, packages, synonyms, users).
- **Proof.** `oracle_tests.rs`: a unique index's exact DDL, a sequence's increment, start, cache and cycle, and an index asked for by a sequence's name refused.
