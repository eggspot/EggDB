## D962 GORM on EggDB through GORM's SQLite dialector — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D16 and D182's ORM list

- `drivers/go/gorm` is a Go module of its own (`github.com/eggspot/EggDB/drivers/go/gorm`), so the driver module stays
  free of dependencies. `eggdbgorm.Open(dsn)` returns GORM's own SQLite dialector configured with the `eggdb`
  `database/sql` driver name, which GORM's SQLite dialector supports (`sqlite.Config{DriverName, DSN}`): GORM's
  SQLite SQL, `AutoMigrate` and its table-recreating migrator run on EggDB's SQLite dialect unchanged.
- **Known cost.** `gorm.io/driver/sqlite` imports `github.com/mattn/go-sqlite3`, so a program using this module also
  links SQLite through cgo even though it never opens it. Writing EggDB's own dialector (its migrator is the bulk of
  the work) removes that and is left for its own batch, with the sqlc check.
- `eggdbgorm_test.go` migrates a model, creates, queries in order, updates, reads one, deletes and counts.
