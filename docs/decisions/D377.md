## D377 SQLite's math functions, `unhex`, `zeroblob` and `randomblob` — Decided by the code-only session (2026-11-10, D355); roadmap M5

SQLite 3.35's built-in math functions and three blob functions, in the SQLite dialect
(`sqlite_math.rs`, reached through the SQLite function table in `parser/sqlite.rs`):

- `acos`, `acosh`, `asin`, `asinh`, `atan`, `atan2(Y, X)`, `atanh`, `ceil`/`ceiling`, `cos`,
  `cosh`, `degrees`, `exp`, `floor`, `ln`, `log(X)` (base 10), `log(B, X)`, `log10`, `log2`,
  `mod(X, Y)`, `pi()`, `pow`/`power`, `radians`, `sin`, `sinh`, `tan`, `tanh` and `trunc`, as
  SQLite documents them: each returns a floating-point value, NULL when an argument is NULL or
  text that does not read as a number, and NULL outside the function's domain (`ln(-1)`,
  `acos(2)`, `mod(X, 0)`). `ceil`, `floor` and `trunc` return an integer argument unchanged.
- `unhex(X [, Y])` reads hexadecimal digits into a blob, skipping the characters of `Y` between
  digit pairs, and gives NULL for any other character or an odd number of digits.
- `zeroblob(N)` is `N` zero bytes and `randomblob(N)` `N` random bytes (at least one), both capped
  at a billion bytes.
