## D1064 More of Flux: the join package, standard packages, query functions and windows in SQL — Decided by the code-only session (2026-11-13, D355); roadmap M16 (D220, D682, D912)

- **Functions defined in the query.** `name = (a, b=default) => expression` (or `=> { return expression }`)
  defines a function that later expressions call with named arguments.
  - The parser inlines each call, replacing the parameters with the argument expressions. Missing arguments
    take their defaults. An unknown or missing parameter is an error.
  - Inlining goes at most 32 levels deep.
  - A bare name that no function binds is an "undefined identifier" error when evaluated.
  - Functions that transform streams (`(tables=<-) => tables |> ...`) are left out.
- **Standard packages in row expressions**, called as `package.function(name: value)` (in
  `crates/eggdb-observability/src/flux/packages.rs`):
  - `strings`: `toUpper`, `toLower`, `trimSpace`, `title`, `strlen`, `hasPrefix`, `hasSuffix`, `containsStr`,
    `trimPrefix`, `trimSuffix`, `replace`, `replaceAll`, `substring`, `repeat` (at most 1 MiB), `index` and
    `countStr`.
  - `math`: the one-argument functions from `abs` to `tanh`, then `pow`, `atan2`, `mod`, `hypot`, `max`,
    `min`, `signbit`, `isInf` and `isNaN`, and the constants `pi`, `e`, `phi`, `sqrt2`, `ln2`, `maxfloat`,
    `smallestNonzeroFloat` and `mInf`.
  - `date`: `year`, `month`, `monthDay`, `weekDay`, `yearDay`, `hour`, `minute`, `second`, `millisecond`,
    `microsecond`, and `truncate(t:, unit:)` for fixed-length units.
  - A null main argument gives null. Durations and RFC 3339 times can now be written inside expressions.
- **The `join` package** (`flux/joins.rs`):
  - `join.inner`, `join.left`, `join.right` and `join.full` take `left:` and `right:` streams, `on: (l, r) =>`
    and `as: (l, r) => ({...})`. `as` may extend either side with `{l with ...}`.
  - `join.time` joins on `_time` and takes `method:`.
  - When `on` is a conjunction of `l.x == r.y` equalities, rows are paired through a hash of those columns.
    Any other predicate compares every pair, up to 50 million comparisons.
  - Outer joins keep unmatched rows, with the other side null. The output is grouped by the left stream's
    group key.
  - Two-parameter functions name their rows' columns `l.x` and `r.y` while they are parsed, so the
    single-row paths are unchanged.
- **`aggregateWindow` pushed into SQL.** When it directly follows `range` and the pushed filters, with
  `mean`, `sum`, `count`, `min` or `max` and no `column` or `timeSrc`, the source query groups by
  `date_bin(every, time, '1970-01-01')` and the aggregate.
  - Only one row per series and window leaves the store.
  - The existing window loop, now `reduce_windows`, fills empty windows (0 for `count`, null otherwise) and
    puts each window's stop in `_time`, as before.
  - Other aggregates still run over the rows read.
