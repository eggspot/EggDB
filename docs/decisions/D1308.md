## D1308 ts_stat with weights — Decided by the code-only session (2026-11-24, D355); roadmap M4 PostgreSQL text search (D1268)

- **What users get.** `ts_stat('query', 'weights')` counts only the positions whose weight is among the letters given (`A` to `D`, in either case), as PostgreSQL does: `nentry` is the number of such positions and `ndoc` the rows with at least one, and a lexeme stored without positions never counts. An empty weights string counts everything, as without it; any other letter fails with PostgreSQL's `unrecognized weight`.
- **How.** The same derived-table rewrite as D1268, with a scalar subquery counting the lexeme's weights that are in the list and the rows where it finds none left out.
- **Left.** A query or weights that are not literals (a parameter or an expression).
- **Proof.** The `ts_stat` test counts weights `ab` and `Ad` across documents with weighted, unweighted and position-less lexemes, counts everything for an empty string, and refuses an unknown letter.
