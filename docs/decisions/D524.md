## D524 Oracle `DBMS_SCHEDULER` jobs on the job scheduler — Decided by the code-only session (2026-11-11, D355); roadmap M10

PL/SQL calls to `DBMS_SCHEDULER` (`CREATE_JOB`, `RUN_JOB`, `DROP_JOB`, `ENABLE`, `DISABLE` and
`SET_ATTRIBUTE`), with positional or `=>` named arguments, are answered by the PL/SQL runtime
beside `DBMS_OUTPUT`, and `eggdb serve`'s job thread runs the jobs each minute, as it runs
pg_cron jobs, MySQL events and SQL Server Agent jobs (D200, D421, D523).

- **Jobs:** `PLSQL_BLOCK` (an anonymous block, wrapped in `BEGIN ... END;` when written without
  one) and `STORED_PROCEDURE` jobs, with `start_date`, `repeat_interval`, `end_date`, `enabled`
  (false by default, as Oracle creates jobs disabled) and `auto_drop` (true by default). Names
  are upper-cased. Errors carry Oracle's codes: ORA-27477 already exists, ORA-27475 not a job,
  ORA-27465 an invalid `repeat_interval`, ORA-27452 a missing value.
- **Calendaring:** `FREQ` (`YEARLY` to `MINUTELY`) with `INTERVAL`, `BYMONTH` (numbers or
  names), `BYMONTHDAY` (`-1` for the last day), `BYDAY` (`MON` to `SUN`), `BYHOUR`, `BYMINUTE`
  and `BYSECOND=0`; parts not given follow the start date's minute, hour, weekday and day, and
  `INTERVAL` counts units of `FREQ` from the start. Times are UTC. `SECONDLY`, `BYSETPOS`,
  `BYWEEKNO`, `BYYEARDAY`, `BYDATE`, numbered weekdays (`1MON`) and named schedules are refused.
- **Running:** a due job runs in its own Oracle session; a one-time job (no `repeat_interval`)
  runs once and is then dropped with `auto_drop` or disabled, as is a repeating job past its end
  date. `RUN_JOB` runs the job now, in the calling session. Jobs live in an internal table in
  `eggdb_internal`, so the file format is unchanged.
- **Left out:** programs, schedules and job classes as objects, job arguments, chains, windows,
  the `*_SCHEDULER_JOBS` dictionary views and run logs.

**Status:** code written, unbuilt (code-only mode, D355).
