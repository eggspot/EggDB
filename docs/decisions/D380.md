## D380 SQLite's `->` and `->>` JSON operators — Decided by the code-only session (2026-11-10, D355); roadmap M5, extends D378

In the SQLite dialect `X -> P` returns the JSON text of the part of `X` that `P` names and `X ->>
P` its SQL value (as `json_extract` with one path, D378); both are NULL when the part is missing.
`P` is a JSON path when it is text starting with `$`, an object label otherwise (`'k'` means
`$."k"`), and an array index when it is an integer (`-1` means `$[#-1]`), as SQLite documents.
They parse where PostgreSQL's JSON operators parse, into the SQLite functions `sqlite_json_arrow`
and `sqlite_json_arrow_text`; PostgreSQL's own `->` and `->>` are unchanged.
