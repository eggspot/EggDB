## D403 Elasticsearch's `_msearch/template` — Decided by the code-only session (2026-11-10, D355); roadmap M8, extends D402

`POST [<index>/]_msearch/template` takes `_msearch`'s newline-separated header and body pairs,
where each body is a template request (`{"source": ..., "params": ...}`, D402). Each body is
rendered with D402's renderer and run as that `_msearch` search; a body whose template fails to
render becomes that search's error item (`general_script_exception`) while the others run, as
Elastic reports per-search failures. Limits, headers, memory accounting and the response shape
are `_msearch`'s own (it is the same code with templating switched on).

**Status:** code written, unbuilt (code-only mode, D355).
