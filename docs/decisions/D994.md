## D994 MySQL's test suite run weekly from outside the repo — Decided by the code-only session (2026-11-13, D355); roadmap M10 (D1, D10, D45)

- A weekly workflow, `.github/workflows/mysql-test-suite.yml`, installs Ubuntu's `mysql-testsuite-8.0` package on the
  runner, starts `eggdb serve --mysql-listen`, and runs every test of the main suite that has a recorded result with
  MySQL's own `mysqltest` client (`scripts/mysql-test-suite.sh`), 60 seconds at most each.
- The suite is GPL software used only as a test tool on the runner: nothing of it enters the repo, a build or a
  release, and no one working on EggDB reads it (D1). EggDB is judged only by whether a test's output matches its
  recorded result.
- The pass rate goes to the run's summary and the per-test results to an artifact kept 90 days, so the rate is
  published every week. `MYSQL_TEST_MINIMUM` (an input or a repository variable, 0 by default) fails the run below a
  given rate, to be raised as the rate grows, as for sqllogictest (D976).
- The workflow runs on Saturdays with the weekly performance pass (D7), not on pull requests.
