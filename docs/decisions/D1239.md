## D1239 SQLTablePrivileges and SQLColumnPrivileges in the ODBC driver — Decided by the code-only session (2026-11-17, D355); roadmap M6f, the ODBC driver (D968)

- **What users get.** `eggdb-odbc` answers `SQLTablePrivileges` (ODBC's seven columns for the tables matching the schema and table patterns) and `SQLColumnPrivileges` (ODBC's eight columns for one table's columns matching the column pattern), with their `W` forms, from the grants D1189 to D1195 store.
- **How.** Catalog queries over `information_schema.table_privileges` and `column_privileges` (D1191), as the other catalog calls do (D972, D1236).
- **Left.** `SQLProcedureColumns`, and the routine and schema privileges, which ODBC has no call for.
- **Proof.** The ODBC integration test lists a table's privileges, every row naming that table.

**Status:** code written, unbuilt (code-only mode, D355).
