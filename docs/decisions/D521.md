## D521 InfluxQL over InfluxDB 1.x's `/query` — Decided by the code-only session (2026-11-11, D355); roadmap M16

The observability listener answers `GET` and `POST /query?q=...` (with `db` and `epoch`) in
InfluxDB 1.x's JSON shape (`results`, `statement_id`, `series` with `name`, `tags`, `columns` and
`values`, or `error` per statement), so Grafana's InfluxDB (InfluxQL) data source and InfluxDB
1.x clients read what line protocol wrote (D220). InfluxQL's grammar is MIT-licensed and public.

- **Translation, not a second engine:** each `SELECT` becomes one PostgreSQL-dialect SQL query
  over the measurement's table in the `metrics` schema: fields and `*`, `::type` casts dropped,
  aggregates `mean` (avg), `count`, `sum`, `min`, `max`, `median` and `percentile` (as
  `percentile_cont`), `spread` (max - min), `stddev` (sample), `first` and `last` (D435's
  TimescaleDB aggregates by `time`); `WHERE` with `now()`, duration literals, `=~` and `!~`
  regular expressions (`~` and `!~`), and nanosecond integers compared with `time`; `GROUP BY
  time(d)` through `time_bucket` and tags (one series per tag combination); `ORDER BY time
  [DESC]`, `LIMIT` and `OFFSET`. An aggregate without `GROUP BY time()` is reported at time 0,
  as InfluxDB does.
- **SHOW:** `DATABASES` (the served database), `MEASUREMENTS`, `TAG KEYS`, `TAG VALUES ... WITH
  KEY = "k"`, `FIELD KEYS` (with InfluxDB's type names) and `RETENTION POLICIES` (one `autogen`);
  `CREATE DATABASE` succeeds without doing anything.
- **Tags and fields:** the store keeps tags and string fields both as `text` columns, so a
  string field is listed among tag keys and string fields are not listed as field keys.
- **Times:** RFC 3339 strings by default, or integers in `epoch` (`ns`, `u`, `ms`, `s`, `m`, `h`).
- **Left out:** `fill()` other than `none` and `null` (empty buckets are not produced), `GROUP BY
  time()` offsets and `GROUP BY *`, `FROM` regular expressions and several measurements,
  subqueries, `INTO`, `SLIMIT`/`SOFFSET` (read and ignored), `tz()`, math between fields,
  `distinct()`, and Flux.

**Status:** code written, unbuilt (code-only mode, D355).
