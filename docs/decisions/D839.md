## D839 VSAM and sequential unloads — Decided by the code-only session (2026-11-12, D355); roadmap D49, D242

- `eggdb import --copybook` (D508) now reads the variable-length forms in which IDCAMS `REPRO` and IEBGENER unload
  VSAM clusters and sequential data sets, from IBM's published record formats: RECFM V (each record led by a record
  descriptor word, as before), VB (records grouped in blocks, each led by a block descriptor word: a 2-byte length
  and two zero bytes, or a 4-byte length with the high bit set for large blocks) and VBS (spanned records whose
  segments are marked first, middle and last in the descriptor's third byte and are joined into one record).
- Fixed-length files still win when the file is a whole number of records; otherwise blocked framing is tried, then
  unblocked. A descriptor with an unknown segment code, a length that runs past its block or file, or a spanned
  record left open makes the file unreadable with one message naming the formats read.
- Left: IMS database unloads, whose segment layouts need the DBD.
