## D1112 A fleet control plane: heartbeat inventory, canary-wave upgrades gated on health, placement by hardware class — Decided by the code-only session (2026-11-13, D355); roadmap M18 (D58, D45)

- **Software operators run, in the one binary.** Any EggDB server becomes the control plane with `--fleet-listen` (D3: no helper service). The inventory, the upgrade plan and when each server reached the target live in its own file (`fleet` keyspace collections), so the control plane is backed up and replicated like any database. Servers join with `--fleet-report <url>` and send a heartbeat every 30 seconds: host name, cluster, region, version, CPU architecture and count, installed memory (from the platform layer where the system says it) and an optional class.
- **Hardware classes.** A server's class is the one its operator gives, or `<arch>-<size>-<storage>` with sizes by CPUs and memory (`small` under 8 CPUs or 32 GiB, `medium` under 32 or 128 GiB, `large` above). A server silent for 90 seconds (three heartbeats) counts as down.
- **Upgrades in canary waves.** `plan_upgrade` puts one canary per hardware class and region in the first wave, so every kind of machine meets the new version first, then the rest in waves by fractions of the fleet. No wave holds two servers of one cluster, so a replication group never loses more than one member at a time. `next_step` lets a wave run only when every server of the previous waves runs the target, is up, and has done so for the soak time. A server that took the target and went down halts the upgrade, and those servers are told to roll back. Each heartbeat's answer carries the version the server should run. Replacing the binary or image is left to whatever runs the servers (the Kubernetes operator, systemd, a deploy tool), which reads the plan from the API.
- **Placement by hardware class.** `place` picks up servers of the requested class, one per region first and then the least loaded, so replicas spread over failure domains.
- **Security.** Every call carries the control plane's password as a bearer token (compared by SHA-256 in constant time), HTTPS is required off the machine, and the inventory is capped at 100,000 servers.
