## D570 The client remembers its window size — Decided by the code-only session (2026-11-12, D355); roadmap M6e, D15, D256

`eggdb-gui` opened at 1280 × 800 every time. It now saves the window's logical size when the user
closes it, as `window.width` and `window.height` in the client settings file (the same file as
the layout and splitter sizes, written the same safe way), and opens at that size next time. A
saved side smaller than the window's minimum or larger than 16,384 is ignored for the default, so
a damaged or hand-edited file cannot open a window too small to use. Scripted runs (`--frames`)
neither read nor write it, so tests and pixel runs stay at the default size. The position is not
kept, since the platform layer does not report or set one yet.

**Status:** code written, unbuilt (code-only mode, D355).
