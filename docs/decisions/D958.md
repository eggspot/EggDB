## D958 A Sequel adapter for the Ruby driver — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D16 and D182's ORM list

- `drivers/ruby/lib/sequel/adapters/eggdb.rb` is a Sequel adapter (`Sequel.connect(adapter: :eggdb, database:
  "app.db")`, or `eggdb://` URLs) over the Ruby driver's `EggDB::Database` in EggDB's SQLite dialect. It includes
  Sequel's own shared SQLite database and dataset methods, so Sequel's SQLite SQL generation, schema parsing and
  table listing apply unchanged, and it is a thin Ruby layer with no protocol or storage logic (D16).
- `execute` yields the last statement's rows, `fetch_rows` turns them into hashes keyed by Sequel's output
  identifiers, `execute_dui` reads the changed-row count from the command tag, and `execute_insert` asks
  `last_insert_rowid()` on the same session. Driver errors become Sequel's database errors.
- ActiveRecord's adapter, a larger interface (schema statements, type maps, quoting and the connection pool's
  contract), is left for its own batch.
- `drivers/ruby/test/sequel_test.rb` creates a table through Sequel's schema DSL and inserts, filters, updates,
  deletes and counts; it skips when the `sequel` gem is absent (a test-only dependency, D1).
