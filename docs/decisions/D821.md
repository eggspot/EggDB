## D821 Authentication rules by database and address — Decided by the code-only session (2026-11-12, D355); roadmap M6b, D185

- A rule-file line may add `database=<name>` (`all` for any) and `address=<ip>` or `address=<ip>/<prefix>`, IPv4 or
  IPv6 (an IPv4 range also matches IPv4-mapped IPv6 peers). The first line whose user, database and address all
  match decides the method, as pg_hba.conf reads top to bottom; a line with an address never matches the local socket.
- `AuthRules::method_for_connection(user, database, address)` is the new lookup, and the PostgreSQL listener uses it
  with the startup database and the peer's IP (`ServerConnection::peer_ip`, new). `method_for(user)`, for callers that
  know neither (the REST API's bearer tokens), takes only lines without `database=` and `address=`.
