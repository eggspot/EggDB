## D699 ISO 20022 messages read as JSON — Decided by the code-only session (2026-11-12, D355); roadmap M16, ISO 20022 and DICOM (D50)

- `iso20022_parse(text) → jsonb` reads an ISO 20022 XML message (a `Document`, or an `AppHdr`) with D690's XML
  parser and returns `{"message": "pacs.008.001.08", "root": "Document", "document": {...}}`: the message
  definition taken from the root's namespace (`urn:iso:std:iso:20022:tech:xsd:<definition>`) and the message as JSON.
- The JSON keeps the message's element names (`GrpHdr`, `CdtTrfTxInf`, `Amt`, ...) without namespace prefixes:
  an element is an object of its children, repeated children are an array, attributes are `@name` members (the
  currency of `<InstdAmt Ccy="EUR">` is `@Ccy`), mixed text is `#text`, and an element holding only text is a string,
  so amounts and codes stay exactly as written.
- A document whose root is not in an ISO 20022 namespace is refused. The message is not checked against its XML
  schema; that, and SWIFT MT messages, are left.

**Status:** code written, unbuilt (code-only mode, D355).
