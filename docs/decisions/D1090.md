## D1090 `wasm32-unknown-unknown` without WASI, database images, and module size budgets — Decided by the code-only session (2026-11-13, D355); roadmap M17 (D6, D8, D221)

- **Why the target matters.** Plain WebAssembly hosts (bundlers, edge runtimes, plugin systems) load modules without WASI. On `wasm32-unknown-unknown` the standard library's file system answers "unsupported", which the engine already handles, but its clocks panic, which "no panics on input" forbids.
- **One time layer.** `eggdb_platform_core::time` re-exports `std::time::{Instant, SystemTime, SystemTimeError, UNIX_EPOCH}` everywhere else, so nothing changes there, and on this target provides the same types over two host imports from the module `eggdb_host`: `monotonic_nanos` and `wall_clock_nanos` (`u64` nanoseconds), plus `sleep` as a wait on the monotonic clock. The crates the module runs (`eggdb`, `eggdb-sql`, `eggdb-platform`) now import their time types from it; `eggdb-sql` gains a dependency on `eggdb-platform-core`. Server-only crates keep `std::time`, since they never run there.
- **Images instead of files.** With no file system, persistence is the host's: `Database::image` (writer turn, checkpoint, every byte of the file) and `Database::from_image` (a memory file holding those bytes, opened for writing). `eggdb-wasm` exports them as `eggdb_wasm_image` and `eggdb_wasm_open_image`; they also serve the WASI build. `web/eggdb-bare.js` is the host: about sixty lines, no WASI shim, the two clock imports, and `image()` for the page to keep in IndexedDB or OPFS.
- **Budgets.** `scripts/footprint-wasm.sh` builds both modules in release and reports `module_bytes` and `module_gzip_bytes` for `wasm32 wasi` and `wasm32 bare`, against first ceilings of 16 MiB and 6 MiB gzipped in `benchmarks/footprint.txt`, checked in the weekly performance pass (D354) and to be tightened to the measured sizes there.
- **CI.** The `browser` job adds the target, builds the bare module and runs `web/test-bare.mjs` under Node (SQL, a clock read, an image round trip).
- **Left.** The GUI card on this target (`eggdb-gui` still reads `std::time`), and a release asset for the bare module.
