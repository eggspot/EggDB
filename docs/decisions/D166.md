## D166 EggDB's own memory allocator: size classes, per-thread caches, a budget, opt-in until measured — Decided by research (build loop, 2026-10-31); refines D41 and D75

Part 4.M1-5 builds the allocator D75 promised for the static Linux builds, whose musl allocator
is slow under many threads. Research of 2026-10-31 asked for new engines behind switches, so it
is opt-in.

- **Shape.** `eggdb_platform::EggAllocator` implements `GlobalAlloc`. Blocks up to 32 KiB use 40
  size classes: 16-byte steps up to 128, then four steps per doubling. Each thread caches up to
  64 KiB of free blocks per class with no lock. It refills 16 KiB at a time from one shared list
  per class, and gives half its cache back when it grows past the limit. New blocks are carved from
  64 KiB runs of 1 MiB chunks, aligned so that a power-of-two class meets any alignment up to
  32 KiB. Larger blocks go straight to the system allocator. A thread's cache goes back to the
  shared lists when the thread ends.
- **State in the process.** The caches, the shared lists and the count of bytes held from the
  system are process-wide, so no `EggAllocator` value owns memory another value could hand out;
  a value carries only its budget. Memory carved for small blocks is reused, never returned to the
  system.
- **Budget (D41).** `EggAllocator::with_budget(bytes)` fails an allocation (returns null) rather
  than hold more than `bytes` from the system, for devices with a fixed amount of memory.
- **The system allocator underneath.** Chunks and large blocks come from `std::alloc::System`,
  which never calls back into the global allocator, so the allocator works on every platform std
  supports, WebAssembly included, without platform code of its own. The shared lists use a spin
  lock that yields, which never allocates.
- **Opt-in.** The `eggdb` binary installs it with `--features egg-allocator`; CI's
  `egg-allocator` job runs the `eggdb` tests and the smoke test under it. `allocator.small_blocks`
  in `eggdb-bench` compares it with the system allocator on each system. Making it the default
  is a later decision, taken from those lines.
