## D1150 The Dart and .NET drivers on the prepared-statement, stepping and COPY calls — Decided by the code-only session (2026-11-14, D355); roadmap M5 (every language driver using the new C API calls, D293)

- **Dart.** A `_StatementApi` looks the statement and COPY calls up once per database.
  - `Database.prepare` returns a `Statement` with `bind`, `execute`, `columns`, `rows` (a `sync*` iterable that
    steps) and `finalize`.
  - `Database.iterate`, `copyFrom` (byte pieces), `copyFromText` and `copyTo` (an iterable of `Uint8List` pieces)
    sit beside it.
  - `int` binds as int64, `double` as a double, `bool` as a boolean, `Uint8List` as a blob, a `DateTime` as ISO 8601
    text, and anything else as its text.
  - Result gathering is shared through `_gathered` and `_converted`.
- **.NET (ADO.NET).** `EggDbCommand.Prepare()` now prepares a native statement (`EggDbPreparedStatement`).
  - Later runs with the same parameter names bind typed values: integers up to `long`, `float` and `double`,
    `bool`, `byte[]`, and the existing text forms for the rest.
  - `ExecuteReader` on a prepared query returns a reader that steps rows from the connection, reading one row
    ahead so `HasRows` is exact.
  - Changing `CommandText` or disposing the command finalizes the statement, and so does closing the connection.
  - `EggDbConnection.CopyFrom(command, Stream | string)` and `CopyTo(command, Stream)` move COPY data in 64 KiB
    pieces.
- An unprepared command still sends its text with text parameters, as before, so existing code behaves the same.
- The checks prepare an `INSERT`, step a `SELECT` and round-trip rows through COPY.
