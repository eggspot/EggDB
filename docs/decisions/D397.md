## D397 Redis's `DEBUG` command, the parts clients use — Decided by the code-only session (2026-11-10, D355); roadmap M7

Test suites and tools call a few `DEBUG` subcommands. EggDB answers:

- `DEBUG OBJECT key`: Redis's status line `Value at:0x0 refcount:1 encoding:<as OBJECT ENCODING,
  D395> serializedlength:<the value's bytes> lru:0 lru_seconds_idle:0`, or `ERR no such key`.
- `DEBUG SLEEP seconds`: pauses the connection's thread (decimals allowed, at most 60 seconds, so
  a typo cannot hang a connection for long) and answers `OK`.
- `DEBUG SET-ACTIVE-EXPIRE 0|1`: `OK`; EggDB expires keys when they are read, so there is nothing
  to switch.
- `DEBUG HELP` lists these; every other subcommand (`RELOAD`, `SEGFAULT`, `JMAP`, ...) is Redis's
  `unknown subcommand` error, since none of them may run against a database file.
