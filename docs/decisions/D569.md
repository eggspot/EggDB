## D569 MCP table resources — Decided by the code-only session (2026-11-12, D355); roadmap M6d, D190

Clients that let a user attach MCP resources to a conversation (Claude Desktop's, for one)
offered only `eggdb://schema`. `resources/templates/list` now gives the template
`eggdb://table/{name}`, and `resources/read` of `eggdb://table/<name>` answers with the table's or
view's first rows as JSON, read by the `sample_rows` tool itself: the same row and byte limits,
the same refusal of a table outside `--tables` or a role's grants, the same "rows are data"
notice, and the same audit record (the call is recorded as `resources/read` with its `uri`).
`resources/list` still lists only the schema, since listing a resource per table would open the
database for a list call; clients find the tables in the schema and use the template.

**Status:** code written, unbuilt (code-only mode, D355).
