## D1149 The Node.js, Ruby and PHP drivers on the prepared-statement, stepping and COPY calls — Decided by the code-only session (2026-11-14, D355); roadmap M5 (every language driver using the new C API calls, D293)

- **Node.js.** The addon gains `prepare`, `stmtBind`, `stmtParameterCount`, `stmtExecute`, `stmtColumns`, `stmtStep`,
  `stmtReset` and `stmtFinalize`, plus `copyIn` and `copyOut`. A prepared handle holds a reference to its connection
  so the session outlives it. `copyOut` calls a JavaScript function for each piece. In JavaScript,
  `Database.prepare` returns a `Statement` with `bind`, `execute`, `run`, `columns`, `iterate`, `all` and `finalize`;
  `Database.iterate`, `copyFrom` and `copyTo` sit beside them. `close` finalizes the statements still open.
  Binding is typed: a safe integer `number` or a lossless `bigint` binds as int64, other numbers as doubles, a
  `Uint8Array` as a blob, a `Date` as its text.
- **Ruby.** `Database#prepare` (with a block that finalizes), `#each_row` (an enumerator stepping rows), `#copy_from`
  and `#copy_to` (with a block per piece, or the whole data). `EggDB::Statement` binds `Integer` (int64 when it fits),
  `Float`, booleans and `nil`, and a binary-encoded `String` as a blob.
- **PHP.** `Connection::prepare` returns an `EggDB\Statement` (`bind`, `execute`, `columns`, `iterate` as a
  generator, `finalize`, also on destruction), and `Connection::iterate`, `copyFrom` and `copyTo` sit beside it.
  PHP strings carry no type, so a string that is not valid UTF-8 binds as a blob and any other string as text.
- The tests and checks prepare an `INSERT`, step a `SELECT` and round-trip rows through COPY.
