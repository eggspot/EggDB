## D1290 bit_length, bit_count, num_nulls, num_nonnulls and uuid_generate_v4 — Decided by the code-only session (2026-11-18, D355); roadmap M4 PostgreSQL functions (D10, D1289)

- **What users get.** `bit_length` of text and binary data, `bit_count(bytea)` (the set bits), `num_nulls(...)` and `num_nonnulls(...)` over any number of arguments of any types, and `uuid_generate_v4()`, the `uuid-ossp` extension's name for a random UUID, which schemas written for PostgreSQL before version 13 use as a column default.
- **How.** Beside `octet_length` and `gen_random_uuid` in `bytea.rs`, with their result types in typing; `uuid_generate_v4` is `gen_random_uuid` under its other name.
- **Left.** `uuid-ossp`'s other generators (`uuid_generate_v1`, `v3`, `v5`), `txid_current` and `pg_current_xact_id`.
- **Proof.** A test reads a text's bit length, a byte string's set bits, both null counts and a generated UUID's length.

**Status:** code written, unbuilt (code-only mode, D355).
