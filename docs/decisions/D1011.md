## D1011 Apache TinkerPop Gremlin over the shared property graph — Decided by the code-only session (2026-11-13, D355); roadmap M13 (D5, D48, D206)

- A new crate, `eggdb-gremlin`, serves Gremlin clients with `eggdb serve --gremlin-listen` (default port 8182,
  loopback only until it has TLS), written from the Apache TinkerPop reference documentation: the Gremlin Server
  WebSocket protocol (requests with `requestId`, `op` and `args`; responses with status 200, 204, 206 for batches,
  401, 407, 498, 499, 500 and 597), GraphSON 3.0 in both directions, SASL `PLAIN` against the server's user (the
  same check as Bolt, D22), and both request kinds clients send: string scripts (`op: eval`, with bindings), read
  by a small parser of the Groovy traversal syntax that accepts traversals and nothing else, and bytecode
  (`op: bytecode`), the form gremlin-python, gremlin-javascript and Gremlin.Net send by default.
- A traversal is compiled into one Cypher query and run with `eggdb_graph::run` on the same graph Bolt and Cypher
  clients use (D206), so the two languages see the same vertices and edges and share one transaction system,
  indexes (D1010) and algorithms. Navigation steps become `MATCH` clauses, filters become `WHERE`, `values`,
  `id` and `label` become `UNWIND`, reducing steps become `WITH ... AS`, `order`, `limit`, `skip`, `range` and
  `dedup` become `WITH ... ORDER BY / SKIP / LIMIT / DISTINCT`, and writes become `CREATE`, `SET` and `DELETE`, with
  a `WITH` between a write and the next read as Cypher requires. Parameters carry every literal, so nothing a
  client sends is spliced into the query text.
- GraphSON vertices carry their properties as vertex properties; an edge's `inVLabel` and `outVLabel` are
  `vertex`, TinkerPop's default label, because the edge record does not hold its ends' labels. GraphBinary is not
  spoken yet: a client must choose GraphSON 3.0 (`GraphSONSerializersV3d0` in gremlin-python).
- Left: `repeat`, `where`, `union`, `coalesce`, `choose`, `group` and the other branching steps, sessions and
  transactions across requests, GraphBinary, TLS, and Cosmos DB's Gremlin API, which waits for D58's legal check.
  CI's `resp-clients` job runs gremlin-python against the server, with scripts and with bytecode.
