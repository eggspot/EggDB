## D1353 Documents queried in MongoDB's query language from the CLI and MCP — Decided by the code-only session (2026-11-25, D355); roadmap M6d "Tools that query documents, search indexes, vectors, graphs and keys in their own query languages (D10, D11)", the documents part

- **What users get.** `eggdb document get <file> <database.collection> [<query>]` reads a document collection on a read-only open: `<query>` is a filter object in Extended JSON (every document when left out) or an aggregation pipeline array. It prints one document per line in relaxed Extended JSON, or `{"documents": [...]}` with `--json`. Agents get the twin `document_get` on every server.
- **Reading only.** The file is opened read-only, and a pipeline that ends in `$out` or `$merge` is refused before it runs (`document_error`), as `eggdb_documents::split_output` finds them. Writing documents through MCP is left for a `document_run` tool with its own confirmation, as `graph_run` has.
- **How.** The same `eggdb_documents` store the MongoDB protocol uses (D197) runs on `DatabaseKeyspace` with the documents' prefix: a filter through `Store::find`, a pipeline through `run_pipeline` over the collection's documents, with `$lookup` loading other collections of the same database. `DatabaseOpener::documents(namespace, query)`, default `None`, answers the tool; the MCP crate's `array_success` (shared with `graph_get` and `graph_run`) cuts whole documents at 1 MiB and says `truncated`. The noun `document` joins `eggdb`'s nouns, with `document_error` as its error code.
- **Left.** Sort, projection and limit as their own arguments (a pipeline does all three now), `document_run`, the change stream, search indexes, vectors and keys.
- **Proof.** The command model's parity test reads an empty collection, restores three orders from a hand-built BSON dump with `eggdb restore`, refuses a namespace without a database and a `$out` pipeline, and compares `document_get` with `eggdb document get --json` for every document, a filter and a `$group` pipeline; the tools list counts 14 tools read-only and 26 with `--allow-write`.
