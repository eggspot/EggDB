## D847 One-argument GROUPING in SQL Server and Oracle — Decided by the code-only session (2026-11-12, D355); roadmap M5, D298

- SQL Server's and Oracle's `GROUPING` takes exactly one argument (`GROUPING_ID` takes several); more is refused as
  each does: SQL Server's error 174 ("The grouping function requires 1 argument(s)."), Oracle's ORA-00909. PostgreSQL
  and MySQL keep their several-argument `GROUPING`.
- An argument that is not a grouping expression keeps SQLSTATE `42803` and now carries each dialect's own error:
  SQL Server's 8161 ("Argument 1 of the GROUPING function does not match any of the expressions in the GROUP BY
  clause.") and Oracle's ORA-00979 ("not a GROUP BY expression").
- Left: grouping sets beside window functions checked against each manual, and `GROUPING` of outer references.
