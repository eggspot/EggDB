## D659 DBMS_RANDOM, DBMS_ASSERT and UTL_MATCH — Decided by the code-only session (2026-11-12, D355); roadmap M10, D434

After `UTL_RAW` and `DBMS_LOB` (D434, D658), these are the Oracle-supplied packages application
code calls most:
- `DBMS_RANDOM` for test data and sampling;
- `DBMS_ASSERT` around every piece of dynamic SQL that security reviews ask for;
- `UTL_MATCH` for fuzzy matching of names.

- They are mapped like D434's packages. The parser turns `package.function(...)` into an
  internal Oracle function with its argument counts, and a new `oracle_more_packages` module types
  and evaluates it. `DBMS_RANDOM.VALUE`, `.NORMAL` and `.RANDOM` may also be written without
  parentheses, as they usually are.
- `DBMS_RANDOM` uses the program's secure random source:
  - `VALUE` is in [0, 1), and `VALUE(low, high)` scales it;
  - `NORMAL` is a standard normal (Box–Muller);
  - `RANDOM` is a signed 32-bit integer;
  - `STRING(opt, len)` takes `u`, `l`, `a`, `x` or printable characters (anything else), at
    most 4000.

  The values come from the secure source, so `DBMS_RANDOM.SEED` would not reproduce a sequence.
  It is left out.
- `DBMS_ASSERT`:
  - `NOOP` returns its argument;
  - `SIMPLE_SQL_NAME` checks a plain identifier (a letter, then letters, digits, `_ $ #`) or a
    quoted one (ORA-44003 otherwise);
  - `QUALIFIED_SQL_NAME` checks dotted names with an optional `@link` (ORA-44004);
  - `ENQUOTE_NAME` upper-cases (unless told not to) and double-quotes, refusing an embedded
    quote;
  - `ENQUOTE_LITERAL` single-quotes, refusing a lone quote inside (ORA-06502).

  `SCHEMA_NAME` and `SQL_OBJECT_NAME`, which look up the catalog, are left.
- `UTL_MATCH`:
  - `EDIT_DISTANCE` is the Levenshtein distance, and -1 when an argument is NULL;
  - `EDIT_DISTANCE_SIMILARITY` is `100 − distance × 100 / longer length`;
  - `JARO_WINKLER` uses prefix scale 0.1 over up to four letters;
  - `JARO_WINKLER_SIMILARITY` is that times 100, rounded down.
- Tests: the module's tests (`kitten`/`sitting` = 3, `MARTHA`/`MARHTA` = 96, the name checks and
  quoting).

**Status:** code written, unbuilt (code-only mode, D355).
