## D810 JetStream object stores — Decided by the code-only session (2026-11-12, D355); roadmap M16, NATS JetStream (D33, D216)

- A NATS object store is a client-side layout over one stream, `OBJ_<bucket>` with the subjects `$O.<bucket>.C.>`
  (chunks under each object's NUID) and `$O.<bucket>.M.>` (one metadata message per object, written with a
  `Nats-Rollup: sub` header). What the server needs is what D722 to D724 already give (rollups, subject purges,
  direct gets, last-per-subject consumers) and one missing piece, now written:
- `$JS.API.STREAM.NAMES` and `$JS.API.STREAM.LIST` honour the request's `subject` (only streams with a subject that
  overlaps it, wildcards on either side) and `offset`, and report the full `total`. Clients list object stores with
  `$O.*.M.>` and find a stream for a subject the same way.
- A test walks an object store's put, replace, purge of the old chunks and metadata read.

**Status:** code written, unbuilt (code-only mode, D355).
