## D898 `WHERE` inside a GQL quantified group — Decided by the code-only session (2026-11-12, D355); follow-up of D884

- A GQL quantified path pattern may end with its own condition, `((x)-[w:WALK]->(p)-[r:RIDE]->(y) WHERE p.open){1,3}`.
  The condition is checked at every repetition: while it is checked, the group's variables are bound to that one
  repetition's nodes and relationships (single values, not the lists they become after the pattern), with the
  row's earlier variables visible too. A repetition that fails it ends no walk, so later repetitions never start
  from it.
- After the pattern the group's variables are still the lists of every repetition (D884).
