## D455 Oracle's `IS [NOT] A SET` and `IS [NOT] EMPTY` — Decided by the code-only session (2026-11-11, D355); roadmap M10 (item 33e)

- `nested_table IS [NOT] A SET` (true when no element repeats) and `nested_table IS [NOT] EMPTY`
  (true when it has no elements) are Oracle's two nested-table conditions beside `MEMBER OF` and
  `SUBMULTISET OF`, which were built. They parse in the `IS` predicate of Oracle's dialect into
  internal calls carrying the negation, and run in `oracle_collections` on the same element
  comparison the `MULTISET` operators use (so `NULL` elements compare as Oracle's multiset rules
  say). A `NULL` collection gives `NULL`; a value that isn't a collection is ORA-00932.
