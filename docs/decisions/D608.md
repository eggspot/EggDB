## D608 ST_AsMVT — Decided by the code-only session (2026-11-12, D355); roadmap M12, D250, D520

D520 wrote `ST_AsMVTGeom` and left `ST_AsMVT`, the aggregate that turns rows into a Mapbox Vector
Tile layer, because it takes a whole row. Tile servers (pg_tileserv, Martin) serve
`SELECT ST_AsMVT(q, 'layer') FROM (SELECT ST_AsMVTGeom(...) AS geom, ...) q` straight from the
database.

- The PostgreSQL dialect's parser rewrites `ST_AsMVT(row [, name [, extent [, geom_name
  [, feature_id_name]]]])` into an internal call, `eggdb_mvt_encode(json_agg(row), …)`. No new
  aggregate is needed:
  - `json_agg` of a FROM label already becomes the whole row as a JSON object;
  - geometries are EWKT text, so they arrive as strings.
- `eggdb_mvt_encode` reads the aggregated rows. Each row becomes a feature:
  - its geometry is the named column, or the first value that reads as WKT/EWKT, as PostGIS
    takes the first geometry column; a row without one is skipped;
  - with a `feature_id_name`, that column's whole number is the feature id;
  - the other non-NULL columns become properties: strings, whole numbers as `int_value`, other
    numbers as `double_value`, booleans, and objects or arrays as their JSON text.
- `eggdb-geo`'s new `mvt::encode_layer` writes MVT 2.1 by hand, with no protobuf crate: a tile
  with one layer (version 2, name, features, shared key and value tables, extent).
  - Geometry is encoded with `MoveTo`/`LineTo`/`ClosePath` commands and zigzag deltas, rounded to
    the grid.
  - A polygon ring drops its closing point and ends with `ClosePath`.
  - The multi forms continue one cursor across their parts.
  - Empty geometries and collections are skipped.
- No rows gives an empty `bytea`, as PostGIS returns.
- Tests use the specification's examples: the point `(25, 17)` is `[9, 50, 34]`, and the polygon
  `(3,6) (8,12) (20,34)` is `[9, 6, 12, 18, 10, 12, 24, 44, 15]`. A SQL test runs the aggregate
  through a subquery.
- Not done: `ST_AsMVT` with `FILTER` or `ORDER BY` inside the call, typed property values beyond
  what JSON carries (a `numeric` with a fraction becomes a double, a date becomes its text), and
  H3 and S2 indexes.

**Status:** code written, unbuilt (code-only mode, D355).
