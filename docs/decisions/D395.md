## D395 Redis's `OBJECT` command — Decided by the code-only session (2026-11-10, D355); roadmap M7

Client libraries, `redis-cli --bigkeys` and memory tools ask `OBJECT ENCODING key`. EggDB keeps
every value in one representation of its own, so `OBJECT ENCODING` answers what Redis 7.2 would
store the value as, from its size and content, with Redis's default thresholds: strings `int`
(a canonical 64-bit integer), `embstr` (44 bytes or less) or `raw`; hashes, sets, sorted sets and
lists `listpack` while they hold at most 128 entries of at most 64 bytes, sets of at most 512
integers `intset`, else `hashtable`, `skiplist` and `quicklist`; streams `stream`. `OBJECT
REFCOUNT` is 1 and `OBJECT IDLETIME` 0 (EggDB keeps neither), `OBJECT FREQ` is Redis's error for a
server without an LFU policy, `OBJECT HELP` lists the subcommands, a missing key is the null
reply, and an unknown subcommand is Redis's `unknown subcommand` error.
