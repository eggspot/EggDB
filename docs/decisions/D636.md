## D636 Handlers and cursors in MySQL trigger bodies — Decided by the code-only session (2026-11-12, D355); roadmap M10, D199, D418, D619

MySQL triggers that total a child table or skip a duplicate write use the same tools as stored
procedures. They declare a cursor, loop over it until a `NOT FOUND` handler sets a flag, and
catch a duplicate key with `DECLARE CONTINUE HANDLER FOR 1062`. D418 built handlers and cursors for
procedures, and D619 gave trigger bodies loops and labels. A trigger with a handler or cursor
was still refused when it was created.

- The trigger body parser reads:
  - `DECLARE CONTINUE|EXIT HANDLER FOR condition[, ...] statement`, where a condition is
    `SQLEXCEPTION`, `SQLWARNING`, `NOT FOUND`, `SQLSTATE [VALUE] 'xxxxx'` or a MySQL error number;
  - `DECLARE name CURSOR FOR SELECT ...`, which takes only a `SELECT`;
  - `OPEN`, `FETCH [[NEXT] FROM] cursor INTO target[, ...]` and `CLOSE`, where a target is a
    local or `NEW.column`.

  Refused: `UNDO` handlers, which MySQL does not run either, and named conditions.
- At run time each `BEGIN ... END` (and each branch or loop body) is a scope. Handlers and cursors
  declared in it end with it, as its locals do.
- When a step fails, the innermost handler in scope that catches the error runs its statement.
  While it runs, only the handlers of outer blocks are in force.
  - A `CONTINUE` handler then goes on with the step after the failing one.
  - An `EXIT` handler leaves the block that declared it.

  The handler classes are:
  - `SQLEXCEPTION`: every class but `00`, `01` and `02`;
  - `SQLWARNING`: class `01`;
  - `NOT FOUND`: class `02`.

  Never caught: a cancelled statement, and the internal signal `INSERT IGNORE` uses to skip a row.
- `OPEN` runs the cursor's query once, with the locals' values at that moment, and keeps its
  rows. `FETCH` takes the next row, or raises `02000` with MySQL's error 1329. MySQL's other
  errors are kept:
  - 1324: an undefined cursor;
  - 1325: the cursor is already open;
  - 1326: the cursor is not open;
  - 1328: a different number of `FETCH` targets than columns.
- Test: `mysql_trigger_bodies_read_cursors_and_catch_errors_with_handlers`. Its trigger:
  - totals a table through a cursor and a `NOT FOUND` handler;
  - marks a row with a `CONTINUE` handler for 1062;
  - skips the rest of a block with an `EXIT` handler;
  - is refused when it uses `UNDO`.
