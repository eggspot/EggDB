## D637 ASOF JOIN ... USING — Decided by the code-only session (2026-11-12, D355); roadmap M11, D447

DuckDB and ClickHouse users write the short form of an ASOF join,
`trades t ASOF JOIN quotes q USING (sym, ts)`. In it the leading columns must be equal, and the
last one is the time, matched to the latest right row at or before the left row's.
D447 took only the `ON` form, and left `USING` out.

- `asof_join` now takes the label of the table on its left: the `FROM` clause's first table, or
  the table of the join just before. After the right table, `USING (columns)` builds the `ON`
  condition D447's rewrite already handles. It is `left.k = right.k` for each leading column,
  and `left.time >= right.time` for the last.
- Both sides need distinct labels, so a table joined to itself needs an alias (a syntax error
  otherwise).
- Unlike a `USING` join's merged columns, `SELECT *` lists the key columns of both sides.
- The first tests of ASOF joins (`asof_tests.rs`) check both forms, `LEFT` keeping a row without
  a match, and the refusal.
- Window joins stay left.
