## D884 GQL quantified groups of several relationships — Decided by the code-only session (2026-11-12, D355); follow-up of D727

- A quantified path pattern may now hold several relationships, `((x:Stop)-[w:WALK]->(p:Platform)-[r:RIDE]->(y:Stop)){1,2}`:
  each repetition walks all of them in order, every node in the group must match its pattern at every repetition,
  and the quantifier counts repetitions (at most 15, D206). The first relationship keeps its place in the pattern;
  the others ride in the group (`QuantifiedGroup.rest`).
- Every variable in the group is a group variable, as in GQL: each node variable is the list of the nodes it matched
  in each repetition, and each relationship variable (with more than one relationship) the list of its relationships,
  one per repetition. A group of one relationship binds as before (D727).
- Path modes (`TRAIL`, `ACYCLIC`, `SIMPLE`) see every relationship walked inside a repetition, so a relationship is not
  reused within one either.
- `WHERE` inside a group is still refused as not supported yet; quantifiers inside a group are a syntax error.

**Status:** code written, unbuilt (code-only mode, D355).
