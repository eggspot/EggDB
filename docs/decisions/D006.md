## D6 Lightweight: size, memory and startup budgets that only shrink — Decided (owner, 2026-10-23)
Every release measures and publishes:
- the binary size;
- idle memory;
- startup time;
- on-disk overhead per row and per index entry.

The numbers may only go down. Features that aren't used cost nothing at runtime. Concrete budgets
are set once the first embedded build works, from measurements against SQLite, Redis and
PostgreSQL on the same hardware.

**Note (D354, 2026-11-10).** The concrete numbers are final targets in `benchmarks/footprint.txt`, set from measurements against SQLite, Redis and PostgreSQL. The weekly performance pass checks them with `scripts/footprint.sh` and trims what is over a target or near it; CI no longer checks size on pull requests. Every release still publishes each binary's size.
