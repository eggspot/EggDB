## D742 Apache ZooKeeper's client protocol: `eggdb-zookeeper` — Decided by the code-only session (2026-11-12, D355); roadmap M15, the etcd v3 gRPC API and the ZooKeeper protocol (D54, D247)

- A new crate, `eggdb-zookeeper`, serves ZooKeeper's client protocol, written from its published protocol and jute
  record descriptions with EggDB's own code; `eggdb serve --zookeeper-listen <address>` (default port 2181) runs it on
  the server's database under the `zookeeper` collections prefix. ZooKeeper clients (the Java client, Curator, Kazoo,
  zkCli) connect unchanged.
- Znodes live in the keyspace: each one's data, ACL and `Stat` (zxids, times, versions, ephemeral owner, child count),
  a child index per parent and an index of ephemeral znodes per session; every request is one transaction, and each
  write takes the next zxid.
- Requests: `create` and `create2` (persistent, ephemeral, sequential with a ten-digit counter from the parent's
  `cversion`; container and TTL znodes are made persistent), `delete`, `exists`, `getData`, `setData`, `getACL`,
  `setACL`, `getChildren`, `getChildren2`, `getAllChildrenNumber`, `getEphemerals`, `sync`, `check`, `multi` (all or
  nothing: on failure the failed operation reports its error, those before it OK and those after it
  RUNTIMEINCONSISTENCY), `ping`, `closeSession`, `setWatches` and `auth` (accepted). Versions make writes conditional
  (`BADVERSION`); other requests answer `UNIMPLEMENTED`.
- Sessions: the connect handshake grants a timeout between 4 and 40 seconds and a session password; a client may
  reconnect to its session with it. A session that sends nothing for its timeout expires: its ephemeral znodes are
  deleted and their watches fire. Ephemeral znodes left by a previous server process are removed at start.
- Watches are one-shot, as ZooKeeper's are: `exists` and `getData` set data watches (`NodeCreated`,
  `NodeDataChanged`, `NodeDeleted`), `getChildren` sets child watches (`NodeChildrenChanged`, `NodeDeleted`), and
  events go to the session's current connection.
- ACLs are kept and returned (`world:anyone` with all permissions when none was given) but not enforced, and SASL is
  not offered, so the listener stays on loopback. Persistent and recursive watches (`addWatch`), quotas,
  reconfiguration, observers and the etcd v3 API are left.
