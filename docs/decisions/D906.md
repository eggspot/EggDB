## D906 OGC API - Tiles on `WorldCRS84Quad` — Decided by the code-only session (2026-11-12, D355); roadmap M12, follow-up of D881

- The OGC API's tiles now come in a second tile matrix set, `WorldCRS84Quad` (OGC 17-083r4 Annex D): longitude and
  latitude in CRS84, origin at (-180, 90), two 256-pixel tiles across at level 0 (`matrixWidth` 2^(z+1),
  `matrixHeight` 2^z), cell size 180 / (256 · 2^z) degrees and the scale denominators of the `GoogleCRS84Quad` scale
  set (a degree taken as 6,378,137 · π / 180 meters, as the standard does).
- `/ogc/tileMatrixSets` lists both sets, `/ogc/tileMatrixSets/WorldCRS84Quad` describes it, and each collection's
  `/tiles` lists a vector tileset per set. A `WorldCRS84Quad` tile is the features transformed to SRID 4326, clipped
  and scaled into the tile's longitude and latitude box with `ST_AsMVTGeom` and encoded with `ST_AsMVT`, exactly as
  `WebMercatorQuad` tiles are in 3857.
- The sets are one `MatrixSet` type in `eggdb-api`'s tiles code, so adding the remaining ones of OGC 17-083r4 is a new
  variant with its CRS, origin and matrix sizes.

**Status:** code written, unbuilt (code-only mode, D355).
