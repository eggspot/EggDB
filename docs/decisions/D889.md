## D889 SPARQL updates, the SPARQL protocols and `eggdb serve --sparql-listen` — Decided by the code-only session (2026-11-12, D355); follow-up of D886 to D888

- `eggdb_rdf::update` runs a SPARQL 1.1 Update request in one write transaction: `INSERT DATA` (each request's blank
  nodes get their own labels, as loads do), `DELETE DATA` (ground, no blank nodes), `DELETE`/`INSERT ... WHERE` with
  `WITH` and `USING` (every solution is found first, then the deletions, then the insertions; templates with an
  unbound variable or an invalid term are skipped per solution; `INSERT` templates make fresh blank nodes per
  solution), `DELETE WHERE`, `CLEAR`/`DROP` (`DEFAULT`, `GRAPH`, `NAMED`, `ALL`; a missing named graph is an error
  unless `SILENT`), `CREATE` (an error when the graph already holds quads, unless `SILENT`; empty graphs are not
  kept), and `ADD`, `MOVE` and `COPY`. A failing operation undoes the whole request.
- `eggdb_rdf::Endpoint` serves the SPARQL 1.1 Protocol at `/sparql` (queries by `GET` or `POST`, updates by `POST`,
  with `default-graph-uri` and `named-graph-uri` replacing the query's `FROM` clauses) and the SPARQL 1.1 Graph Store
  HTTP Protocol with indirect graph identification at `/rdf-graphs` (`?graph=<iri>` or `?default`: `GET`, `PUT`,
  `POST`, `DELETE`). Results follow `Accept` or `format`; errors are 400 for syntax and invalid requests, 501 for what
  is not written yet, 500 for storage. Requests sign in with HTTP Basic as the server's user.
- `eggdb serve --sparql-listen <address>` (default port 3030, loopback only until the endpoint has TLS, like the
  other new HTTP listeners) runs it over the database file's collection `rdf0` (`eggdb::keyspace::RDF_COLLECTIONS`),
  under the server's request size limit, memory budget and `--rate-limit`; `--read-only` refuses updates and graph
  changes with 403.
- Left: `LOAD` and `SERVICE` (fetching by IRI), roles and grants on RDF data, an RDF import and export command in
  the CLI, RDF in the MCP tools, the W3C SPARQL test suite in CI, and RDF-star.
