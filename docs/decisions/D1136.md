## D1136 Inner joins ordered by estimated size from ANALYZE statistics — Decided by the code-only session (2026-11-14, D355); roadmap M5 (a cost-based optimizer that orders joins; the optimizer using the histograms for ranges; D40, D100, D178, D786)

- **What changes.** A `SELECT` whose `FROM` holds only inner and cross joins of plain tables (no outer joins, `USING`,
  `NATURAL`, derived tables, functions or `WITH` queries) is now joined in the order the estimates favour, not the
  order it was written. A query written with the big table first no longer scans it in the outer loop.
- **The estimates.** Each table's rows are its `ANALYZE` count (D786) times the selectivity of the conditions on that
  table alone (qualified with its name or alias):
  - an equality uses the value's most-common frequency, or the rest of the rows spread over the other distinct
    values;
  - `<`, `<=`, `>` and `>=` read the histogram's equal-population buckets, interpolating inside a bucket when the
    bounds are numbers;
  - `IS [NOT] NULL` uses the null fraction, and `IN` adds up its equalities;
  - anything else counts 0.33 (0.1 for an equality without statistics).

  This is PostgreSQL's estimation scheme, implemented from its documentation.
- **The order.** Greedy, as SQLite's and PostgreSQL's planners do above a size: the smallest estimated table first,
  then each time the smallest table joined by an equality to one already placed, falling back to the smallest left
  when none is joined. The `ON` conditions move to `WHERE`, where the join step already finds key equalities for
  index probes and hash joins (`with_where_keys`), so access paths are unchanged.
- **When it stays as written.** A plain `*` select list (the column order follows `FROM`), a table never analyzed
  (no basis to choose), or more than twelve tables.
- **Left:** outer joins (which need the reordering rules of associativity), costing join methods against each other,
  extended statistics for correlated columns (`CREATE STATISTICS`), and re-planning during execution (M5's
  adaptive item).

**Status:** code written, unbuilt (code-only mode, D355).
