## D1318 Set-returning WebAssembly functions — Decided by the code-only session (2026-11-25, D355); roadmap M5 `LANGUAGE wasm` (D793, D862)

- **What users get.** A `LANGUAGE wasm` function may be declared `RETURNS SETOF <type>` for any type a wasm function returns (D793, D862), and is used in `FROM` (and wherever a set-returning function is) like a PL/pgSQL one. The export takes the SQL arguments and then one more `i32`, the row's index from 0, and returns an `i32` before the value: 1 with a row, 0 when there are no more rows. `CREATE FUNCTION` checks that shape.
- **How.** Every row of one call runs on the same instance of the module, so the module may keep its state in memory between rows (an iterator) or compute each row from its index. The rows are charged to the statement's value limit, the cancel flag is checked between rows, and more than ten million rows fail with 54000. A `NULL` argument (or a strict function's) gives no rows.
- **Left.** `RETURNS TABLE`, rows of several columns, and host functions with effects behind permissions, and per-role limits.
- **Proof.** A test module counting from 1 to `n` returns three rows for 3 and none for 0, and a declaration whose value type does not match the export is refused.

**Status:** code written, unbuilt (code-only mode, D355).
