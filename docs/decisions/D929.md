## D929 Renaming and counting collections in the C API — Decided by the code-only session (2026-11-13, D355); roadmap M4, follow-up of D139 and D292

- `eggdb_rename_collection(txn, name, new_name)` renames a collection in a write transaction as
  `WriteTransaction::rename_collection` does (D292): one commit of two keys whatever the collection's size;
  `EGGDB_ERR_COLLECTION_NOT_FOUND` for a missing collection and `EGGDB_ERR_ALREADY_EXISTS` for a taken name.
- `eggdb_collection_stats(txn, name, &stats)` fills `eggdb_collection_stats { entries, key_bytes, value_bytes }` from
  the count each collection keeps, in a read transaction; a write transaction is refused with
  `EGGDB_ERR_INVALID_ARGUMENT`, since its counts move with its own uncommitted writes.
- The language drivers wrap these next, with the rest of D292 in each driver.
