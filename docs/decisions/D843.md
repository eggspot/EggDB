## D843 CQL `ALTER TYPE` — Decided by the code-only session (2026-11-12, D355); follow-up of D809

- `ALTER TYPE [ks.]name ADD [IF NOT EXISTS] field type` appends a field; `ALTER TYPE [ks.]name RENAME [IF EXISTS]
  a TO b [AND c TO d ...]` renames fields. Adding an existing field, renaming an unknown one or onto a taken name is
  refused as Cassandra does.
- A user type is stored by position (D809), so neither change touches rows: values written before an `ADD` read
  the new field as null, and a rename changes only names. The type's definition in `eggdb_cql.types` is rewritten,
  and every table in the keyspace that keeps the old definition in its column types (D809 stores it whole) gets the
  new one by text replacement, in the same statement. It reports an `UPDATED TYPE` schema change.
