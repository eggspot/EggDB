## D506 Excel `.xlsx` import and export — Decided by the code-only session (2026-11-11, D355); roadmap M11

`eggdb import --xlsx <file> --table <name>` loads the first worksheet of an Excel workbook into a SQL
table, and `eggdb export --xlsx <file> --table <name>` writes a table as a workbook, the same way
`--ndjson` and `--parquet` do (D505, D202).

- **Where:** the reader and writer live in `eggdb-content` (`read_sheet`, `write_sheet`,
  `SheetCell`), next to the ZIP reader and the OOXML text extraction it already has; the CLI's
  `xlsx_io.rs` turns rows into table columns and back.
- **Reading:** the first `<sheet>` of `xl/workbook.xml`, found through the workbook's
  relationships; shared strings, inline strings, booleans, error values and formula results (the
  cached value) are read. Numbers whose cell style has a date format (built-in formats 14 to 22
  and 45 to 47, or a custom format with `y`, `d`, `h` or `s` outside quotes and brackets) become
  dates or timestamps, in the 1900 system (with Excel's false 1900-02-29) or the 1904 one.
- **Bounds:** every part read counts against one decompression limit (2 GiB), the file itself at
  most 1 GiB, and cell references that skip ahead may create at most eight empty slots per byte of
  sheet XML, so a few bytes can't ask for a million rows of padding.
- **Columns:** the first row names them; a blank heading becomes `column<n>` and a repeated one
  gains `_2`, `_3`. Rows with no value are skipped. Each column takes the narrowest type that holds
  all its values: boolean, integer, double, date, timestamp, else text.
- **Writing:** a heading row, then the rows; text as inline strings, dates and timestamps as
  date-formatted serials, every part stored uncompressed by a new `write_stored` ZIP writer
  (EggDB has no DEFLATE encoder yet; Excel, LibreOffice and other readers open stored entries).
  Timestamps with a zone are written as their UTC wall time; integers past 2^53 lose precision
  in Excel, which keeps doubles.
- **Left out:** `.xls` (MS-XLS) waits for D58's legal check as the roadmap says; other sheets,
  merged cells and formulas themselves are not read.

**Status:** code written, unbuilt (code-only mode, D355).
