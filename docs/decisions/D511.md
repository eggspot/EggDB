## D511 Trino's client REST protocol — Decided by the code-only session (2026-11-11, D355); roadmap M10

`eggdb serve --trino-listen <address>` serves Trino's client REST protocol in a new crate,
`eggdb-trino`, the first step of "Trino/Presto SQL: first the client REST protocol". Trino is
Apache-licensed and its client protocol is documented publicly.

- **Statements:** `POST /v1/statement` runs the body. Trino's protocol lets any response carry
  data, so the first response already holds the columns and the first page; there is no queued
  state. Results larger than 10,000 rows keep the rest in memory under the query id and answer
  `GET <nextUri>` page by page; `DELETE` drops them; at most 64 queries wait at once, and a
  result not fetched within ten minutes is dropped (410 afterwards).
- **Types:** each column's Trino type and `typeSignature` from its SQL type: the integers,
  `real`, `double`, `boolean`, `decimal(p,s)`, `date`, `timestamp(6)`, `timestamp(6) with time
  zone`, `json`, `uuid`, `varbinary` (base64 values) and `varchar` for the rest; a column whose
  type is not known before the rows are read is `varchar` and its values are strings. Non-finite
  doubles are the strings `NaN`, `Infinity` and `-Infinity`, as Trino sends them.
- **Updates and errors:** a statement without rows answers `updateType` and `updateCount` from
  its command tag; a failed one answers Trino's `error` object (`SYNTAX_ERROR`,
  `TABLE_NOT_FOUND`, `COLUMN_NOT_FOUND`, `PERMISSION_DENIED`, `INVALID_CAST_ARGUMENT`,
  `CONSTRAINT_VIOLATION`, else `GENERIC_USER_ERROR`, all `USER_ERROR`) with state `FAILED`.
- **Sign-in:** HTTP Basic with the server's user and password, as the REST API (D235) does.
  Stock Trino clients send a password only over HTTPS, so they connect once the HTTP listeners
  have TLS; `X-Trino-User` alone is not trusted.
- **Left out:** Trino's SQL dialect, functions and catalogs (`X-Trino-Catalog` and
  `X-Trino-Schema` are ignored), session properties, prepared statements and transactions over
  headers, and TLS.

**Status:** code written, unbuilt (code-only mode, D355).
