## D1240 SQLProcedureColumns in the ODBC driver — Decided by the code-only session (2026-11-17, D355); roadmap M6f, the ODBC driver (D968, D1237)

- **What users get.** `eggdb-odbc` answers `SQLProcedureColumns` (and `SQLProcedureColumnsW`): each parameter of the functions and procedures matching the schema, routine and parameter patterns, with ODBC's nineteen columns, its mode as `SQL_PARAM_INPUT`, `SQL_PARAM_INPUT_OUTPUT` or `SQL_PARAM_OUTPUT`, its ODBC type and its position, so tools that build a call dialog for a stored procedure can fill it.
- **How.** A catalog query over `information_schema.parameters` joined to `routines` by specific name, as the other catalog calls do (D972).
- **Left.** Return values (`SQL_RETURN_VALUE`) and result columns (`SQL_RESULT_COL`) of functions, whose types `information_schema.parameters` does not list, and parameter defaults.
- **Proof.** An ODBC integration test on a PostgreSQL-dialect connection: a two-parameter SQL function's parameters come back in order as inputs.

**Status:** code written, unbuilt (code-only mode, D355).
