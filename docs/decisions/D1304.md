## D1304 jsonb_set_lax — Decided by the code-only session (2026-11-18, D355); roadmap M4 PostgreSQL JSON functions (D10)

- **What users get.** PostgreSQL 13's `jsonb_set_lax(target, path, new_value[, create_if_missing[, null_value_treatment]])`: a non-NULL value sets as `jsonb_set` does; an SQL NULL is stored as JSON `null` (`use_json_null`, the default), deletes the key (`delete_key`), leaves the target as it was (`return_target`), or fails with PostgreSQL's 22004 and its detail and hint (`raise_exception`); another treatment is refused.
- **How.** Built on `jsonb_set` and the `#-` operator's path deletion.
- **Left.** Nothing of its own.
- **Proof.** A test sets JSON null by default, deletes the key, sets a value, and raises for a NULL with `raise_exception`.
