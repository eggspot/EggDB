## D1158 AES on the processor's AES instructions — Decided by the code-only session (2026-11-14, D355); roadmap M6a (D161, D23)

- **When.** `eggdb_crypto::Aes` detects AES-NI with SSE 4.1 on x86-64, or the Armv8 Cryptography Extension's
  AES instructions on AArch64, when the cipher is made. When they are there, encryption and decryption go
  through them. Everywhere else, and on processors without them, the computed bit-sliced cipher of D161 runs as
  before. Every user of the cipher (AES-GCM for TLS and page encryption, FF1, key wrapping) gains without a
  change. `Aes::uses_processor_instructions` reports which path a cipher takes.
- **x86-64.**
  - Encryption: `AESENC` for the middle rounds, `AESENCLAST` for the last.
  - Decryption: FIPS 197's equivalent inverse cipher, `AESDEC` with each middle round key passed through
    `AESIMC`, then `AESDECLAST`.
- **AArch64.**
  - Encryption: `AESE` and `AESMC` per round, then `AESE` and a final XOR.
  - Decryption: `AESD` with the last round key, then for each middle round the XOR of its key, `AESIMC` and
    `AESD` with a zero key, then the first round key.
- **Safe code inside.** Blocks move in and out of registers through value intrinsics (`_mm_set_epi64x` and
  `_mm_extract_epi64`, `vcreate_u64` and `vgetq_lane_u64`), with no pointer loads. The only `unsafe` is the call
  into each `#[target_feature]` function right after the feature check, one operation per block with its
  `SAFETY` note, as in CRC32C's hardware path (D1).
- **Still constant time.** The instructions take the same time for every key and block, so the side-channel
  property of D161's computed S-box holds on both paths.
- **Tests.** A test checks both paths give the same ciphertext and plaintext for 128-, 192- and 256-bit keys over
  nine blocks; the FIPS 197 vectors run on whichever path the machine has. CI runs on x86-64 and AArch64
  machines, so both instruction sets are covered.

**Status:** code written, unbuilt (code-only mode, D355). Security-relevant: the hardware path needs the
security review pass of D35 when the batch is built.
