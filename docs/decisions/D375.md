## D375 Oracle's `STATS_MODE` — Decided by the code-only session (2026-11-10, D355); roadmap M5

Oracle's `STATS_MODE(expr)` returns the most frequent value of a group, ignoring NULLs, and any one
of several equally frequent values. EggDB already has PostgreSQL's ordered-set `mode() WITHIN
GROUP (ORDER BY expr)` (D151), so in the Oracle dialect `STATS_MODE(expr)` parses into that
aggregate ordered by `expr` ascending, which picks the smallest of the tied values: one of the
values Oracle may return, and the same every time. It is an aggregate, not an analytic function,
as in Oracle. The other `STATS_*` functions (binomial, crosstab, F, Kolmogorov-Smirnov,
Mann-Whitney, one-way ANOVA, t and Wilcoxon tests) need the distribution functions and stay on the
roadmap.
