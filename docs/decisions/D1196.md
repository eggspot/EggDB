## D1196 Key sources: environment, programs, Vault and AWS KMS — Decided by the code-only session (2026-11-17, D355); roadmap M6b (D23, D187); security-critical (D35)

- **What users get.** `--key-source <source>` gives an encrypted database its key from where companies keep keys, not only from a file: `env:<NAME>`, `command:<command line>` (any program that prints the key: an HSM vendor's tool, `pkcs11-tool`, a cloud secret manager's CLI), `vault:<URL>#<field>` (a HashiCorp Vault key-value secret, `VAULT_TOKEN`, `VAULT_NAMESPACE`), `vault-transit:<URL>@<file>` (Vault's Transit engine unwraps a wrapped key kept beside the database, so the plain key never rests on disk) and `aws-kms:<region>@<file>` (AWS KMS's `Decrypt` of a ciphertext blob, signed with Signature Version 4 from `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` and `AWS_SESSION_TOKEN`; `AWS_ENDPOINT_URL_KMS` for a compatible service). Each gives 64 hexadecimal digits or the base64 of 32 bytes, the key `--key-file` takes.
- **How.** One CLI module, `cli/key_sources.rs`, over the HTTP client (with TLS and certificate checks) and the SigV4 signer EggDB already has for S3; answers are read by a small JSON string reader, enough for Vault's and KMS's flat answers. Nothing is added to the engine: it still receives 32 bytes.
- **HSMs.** A PKCS#11 module is a vendor's C library, which EggDB would load at run time; `command:` reaches every HSM through its vendor's tool without that, and a native PKCS#11 source is left for later.
- **Proof.** Unit tests: hex and base64 keys and refusals, the JSON reader, an unknown kind, an unset variable, and a program's output as the key.
- **Left.** Azure Key Vault and Google Cloud KMS (their token flows), rotating to a new key online (the next roadmap item), and the server reading a key source per database.
- **Security review.** As a D35 change it needs a security-only review pass once built: that keys never reach logs or error text, and that `command:` is the operator's own command line.

**Status:** code written, unbuilt (code-only mode, D355).
