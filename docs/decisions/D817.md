## D817 Audited reads of chosen tables — Decided by the code-only session (2026-11-12, D355); follow-up of D815

- `eggdb serve` with `EGGDB_AUDIT=1` and `EGGDB_AUDIT_TABLES=salaries,patients` records an `audited_read` server event
  for every statement, from any protocol, that names one of those tables and is not already recorded as a schema or
  privilege change: its user, database, protocol, text and whether it succeeded.
- A statement is matched by its tokens: a word or quoted identifier equal to a chosen table name, in any case, without
  the schema. That errs toward more records (a column or alias of the same name matches too) and does not see a read
  through a view or routine of another name; matching on the bound statement's tables, so views count, is left.
- The list is set once per process (`audit_events::set_audited_tables`), so a session cannot turn it off.
