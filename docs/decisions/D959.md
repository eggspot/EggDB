## D959 Drizzle and Knex adapters for the Node.js driver — Decided by the code-only session (2026-11-13, D355); roadmap M6f, D16 and D182's ORM list

- **Drizzle.** `require('eggdb/drizzle').drizzle(database)` returns Drizzle's SQLite proxy driver
  (`drizzle-orm/sqlite-proxy`) over an embedded `Database` in EggDB's SQLite dialect: the proxy callback runs each
  statement with its parameters and hands back the last result's rows as value arrays (`get` the first row, `run`
  none), and the batch callback runs a batch in one transaction. Drizzle's `sqlite-core` schema and query builder are
  used unchanged.
- **Knex.** `require('eggdb/knex')` is a Knex client class (`knex({ client: ClientEggDb, connection: { filename } })`)
  extending Knex's own SQLite client, so Knex's SQLite query and schema compilers are used unchanged; it opens
  `Database` connections, runs `_query` through `execute` with the bindings, answers rows as objects, and fills the
  `lastID` (from `last_insert_rowid()` on the same session) and `changes` (from the command tags) that Knex's SQLite
  response processing reads. Streams are refused for now.
- Both are thin JavaScript layers with no protocol or storage logic (D16); `drizzle-orm` and `knex` are the user's
  dependencies, not the package's, and `test/orm.test.js` skips each when it is absent.
- **Left.** Prisma needs a driver adapter in its own interface (and a query engine that accepts it), TypeORM and
  Sequelize a dialect each; they come next.
