## D547 A RESP connection opens on its first key space — Decided by the code-only session (2026-11-11, D355); roadmap M6e, issue #29, D329

A query tab cannot run anything over RESP (`Query tabs need a SQL connection`), so the empty
`Query 1` a RESP connection opened with was a dead end. The window now opens on the keys tab of
the first key space the server lists (`db0`, which is always listed) and starts its scan, as `Enter`
on that key space in the tree does (D329). The keys tab takes `Query 1`'s session, so the strip
still holds one tab. A SQL connection, or a RESP server that lists no key space, still opens on
`Query 1`, and closing the last tab still leaves an empty `Query 1` (`docs/ux/workspace.md` 9).

**Status:** code written, unbuilt (code-only mode, D355).
