## D640 Reading dictionary-encoded Arrow columns — Decided by the code-only session (2026-11-12, D355); roadmap M11, D240, D573

pandas categoricals, Polars `Categorical` and DuckDB `ENUM` columns reach Arrow as
dictionary-encoded columns, and so do most string columns that pyarrow writes from Parquet. D573's
reader refused every stream that had one.

- A field with a `DictionaryEncoding` (field slot 4) keeps its value type from the field's type.
  It also gets an index type: the encoding's `Int`, 8 to 64 bits, signed unless it says otherwise,
  and a signed 32-bit integer when the encoding names none.
- A `DictionaryBatch` (id, one-column record batch, `isDelta`) is decoded with its column's value
  type. A plain one replaces that id's values, and a delta appends to them. A dictionary batch
  whose id no field uses is damage. Dictionaries together hold at most as many values as a stream
  may hold rows, and compressed dictionary batches are refused like compressed record batches.
- In a record batch, a dictionary-encoded column reads its indices, then looks each one up. A
  null index is a null, and an index outside the dictionary is damage. So is a batch that uses a
  dictionary never sent. The column comes back as a plain column of its value type.
- Files work too, since the reader walks the file's messages in stream order.
- Writing stays plain: EggDB writes no dictionaries.
- Test: a hand-built stream with a UTF-8 dictionary of `int8` indices, a delta, a null and a
  missing dictionary.
