## D273 A SQLite table's `CREATE TABLE` text is kept as written in its own catalog key space `0x15`, beside the generated text it was saved with — Decided by the build loop (EggAgentCode task 20261102-0614, 2026-11-02); roadmap item 32, applies D9, D10, D20 and D114

SQLite keeps each table's `CREATE TABLE` statement as the application wrote it and shows it in
`sqlite_schema.sql` and the shell's `.schema`. Tools and migration libraries compare that text, so
EggDB's generated text (`CREATE TABLE t (a INTEGER)` for `CREATE TABLE t(a int)`) made them see a
changed schema. Table definitions keep columns and types, not text, and adding the text to them
would need a new table-definition version for every SQLite table.

- **Where.** One record per table under the SQL prefix, `0x15` and the table's internal name
  (`SQLITE_TEXT_SPACE` in `crates/eggdb-sql/src/sqlite_schema_text.rs`). The space numbers
  `0x10` to `0x14` are statistics, roles, grants, policies and row security; `0x15` was the
  next free one.
- **Layout.** Record version `1`, the generated `CREATE TABLE` text's length as a 32-bit
  little-endian number, that text, then the original text up to the end of the value, both UTF-8.
  Any other version, a length past the end or text that is not UTF-8 is damage: an error naming
  the `CREATE TABLE` text (`XX001`), never a panic.
- **When it is written and read.** A `CREATE TABLE` in SQLite's dialect that makes a new,
  non-temporary table writes it. `sqlite_schema` shows the original text only while the
  generated text of the table as it is now equals the saved one; otherwise it shows the generated
  text, so a stale original is never shown. `ALTER TABLE` and `DROP TABLE` delete the record, and
  tables outside `public` always show the generated text.
- **Ownership.** The key counts as its table's own setting, like statistics and row security, so
  `eggdb mcp --tables` (D156, D257) shows and protects it with its table.
- **Compatibility.** The space arrives before v0.2.0 ships and is part of its format (D20,
  D124); a later change to the layout needs record version 2.

Left: keeping the original text across `ALTER TABLE ... RENAME` and `ADD COLUMN` (SQLite edits
the text in place), and the original text of indexes, views and triggers in `sqlite_schema`.
