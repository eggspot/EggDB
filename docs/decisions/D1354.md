## D1354 Search indices queried with the query DSL from the CLI and MCP — Decided by the code-only session (2026-11-25, D355); roadmap M6d "Tools that query documents, search indexes, vectors, graphs and keys in their own query languages (D10, D11)", the search part

- **What users get.** `eggdb search get <file> <index> [<body>]` runs one search request body on one full-text index of the file, on a read-only open, and prints the JSON response `POST /<index>/_search` gets from `eggdb serve --es-listen` (D196): the same scoring, sorting, `_source` filtering, aggregations, highlighting and `knn`. Agents get the twin `search_get` on every server.
- **One implementation.** The command builds the HTTP request in process and hands it to `eggdb_esrest::Api::answer`, so the CLI and the tool can never drift from the REST API. The API checks basic authentication on every request, so each call makes an `Api` with a fresh in-process password that never leaves the process; nothing listens on a port. The file is opened read-only, and only `POST /<index>/_search` is ever built, so a call cannot change an index. An index name with `/`, `?`, `#`, `%` or white space is refused before the request is built, so a name cannot reach another endpoint.
- **Results.** A status other than 200 is `search_error` with the status and the API's error body. The tool keeps the response's fields and cuts `hits.hits` at 1 MiB, saying `truncated`.
- **How.** `DatabaseOpener::search(index, body)`, default `None`; `eggdb mcp`'s file opener runs it with the CLI's `search_index`. The noun `search` joins `eggdb`'s nouns, with `search_error` as its error code.
- **Left.** Several indices or patterns in one call (`a,b`, `logs-*`), `_count`, scroll and point-in-time paging through MCP, a CLI way to index documents (the parity test can only check failures until then), vectors and keys.
- **Proof.** The command model's parity test checks that a missing index fails with the same code and category from `eggdb search get --json` and `search_get`, that path-like names are refused, and that an unknown argument is `invalid_arguments`; the tools list counts 15 tools read-only and 27 with `--allow-write`.
