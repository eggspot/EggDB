## D1250 `pg_publication_rel` shows column lists and row filters — Decided by the code-only session (2026-11-18, D355); roadmap M14 (D1248, D1249)

- **What users get.** `pg_publication_rel.prattrs` lists a published table's column list as the columns' numbers (`1 2`), and `prqual` holds its row filter, both NULL when the table is published whole, so `psql`'s `\dRp+`, pgAdmin and other tools show what a publication sends.
- **How.** The catalog row reads the stored publication's lists and filters; the column numbers come from the table's definition. `prqual` holds the expression's SQL text, not PostgreSQL's internal node tree, which tools pass to `pg_get_expr` to show.
- **Left.** `pg_get_expr` answering that text as it is, when the built pass shows it does not already.
- **Proof.** The publications test reads `prattrs` back.
