## D888 SPARQL 1.1 queries evaluated — Decided by the code-only session (2026-11-12, D355); follow-up of D886 and D887

- `eggdb_rdf::query` runs a SPARQL 1.1 query on a snapshot of the RDF database, following the algebra's semantics
  (section 18.5): basic graph patterns joined triple by triple, each triple read from the index whose leading
  positions are bound (D886); left joins with their conditions; union; minus (only solutions sharing a variable
  remove one); filters with SPARQL's three-valued `||` and `&&`; `BIND`; `VALUES`; `GRAPH` with an IRI or a variable;
  sub-`SELECT`s; and `EXISTS`/`NOT EXISTS`.
- The dataset is the default graph and every named graph, or `FROM` graphs merged as the default graph and `FROM
  NAMED` graphs as the named ones. Property paths are evaluated over term pairs: sequences, alternatives, inverses,
  negated property sets, and `*`, `+` and `?` as breadth-first closures with set semantics, starting from whichever
  end is bound (every node of the active graph when neither is).
- Expressions follow section 17: effective boolean values, numeric promotion (integer, decimal, double; integer
  division gives a decimal; division by zero is an error except in doubles), value comparison of numbers, strings,
  booleans and date-times, `IN`/`NOT IN`, and the built-in functions (`STR`, `LANG`, `LANGMATCHES`, `DATATYPE`,
  `BOUND`, `IRI`, `BNODE`, `RAND`, `ABS`, `CEIL`, `FLOOR`, `ROUND`, `CONCAT`, `SUBSTR`, `STRLEN`, `REPLACE`, `UCASE`,
  `LCASE`, `ENCODE_FOR_URI`, `CONTAINS`, `STRSTARTS`, `STRENDS`, `STRBEFORE`, `STRAFTER`, `YEAR` ... `SECONDS`,
  `TIMEZONE`, `TZ`, `NOW`, `UUID`, `STRUUID`, `COALESCE`, `IF`, `STRLANG`, `STRDT`, `sameTerm`, the `is...` tests,
  `REGEX`, and XSD casts). `REGEX` and `REPLACE` use our own small backtracking matcher over XPath's common syntax,
  with a step budget so a hostile pattern fails instead of hanging; `REPLACE` with group references and the hash
  functions (`MD5`, `SHA1`, ...) are type errors for now.
- Grouping and aggregates (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `SAMPLE`, `GROUP_CONCAT`, with `DISTINCT`), `HAVING`,
  projection expressions, `ORDER BY` in SPARQL's term order, `DISTINCT`/`REDUCED`, `OFFSET` and `LIMIT`. `CONSTRUCT`
  instantiates its template per solution with fresh blank nodes; `DESCRIBE` returns the triples whose subject is
  each resource.
- Results are written as SPARQL 1.1 Query Results JSON, the XML format, CSV and TSV (`eggdb_rdf::write_results`,
  chosen by `ResultFormat::negotiated` from an `Accept` header); graphs as N-Triples.
- Intermediate results are limited to 1,000,000 solutions and path closures to 1,000,000 nodes; past that the query
  fails rather than exhausting memory.
