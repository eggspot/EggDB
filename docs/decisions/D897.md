## D897 Dictionary-encoded values inside nested Arrow columns — Decided by the code-only session (2026-11-12, D355); follow-up of D640 and D860

- `eggdb-arrow`'s reader now reads dictionary-encoded fields inside lists, fixed-size lists, maps, unions and
  structs: such a child is an encoded leaf holding its dictionary id, its index type and its value type; its rows
  are read as indices and looked up in the dictionary batch with that id (deltas appended, as at the top level)
  before they are written into the column's JSON text.
- A dictionary batch now belongs to the column whose top-level field or any nested field carries its id. A
  dictionary whose values are themselves nested (a dictionary of lists or structs) is still refused by name.
- An index outside its dictionary, or a dictionary never sent, fails the read as damaged input.

**Status:** code written, unbuilt (code-only mode, D355).
