## D709 read_netcdf — Decided by the code-only session (2026-11-12, D355); roadmap M11, arrays: SQL/MDA, Zarr, HDF5 and NetCDF (D57)

- `read_netcdf(path)` (PostgreSQL dialect) reads a NetCDF classic file through the session's file reader (D703):
  CDF-1, the 64-bit-offset CDF-2 and the 64-bit-data CDF-5, with every numeric type (bytes, shorts, ints, int64s and
  their unsigned forms, floats and doubles) and characters.
- It returns one row per element of every variable: `variable` (its name), `coordinates` (`bigint[]`, row-major,
  the record dimension first for record variables), and `value` as `double precision`, or `text` for a character
  variable, whose last dimension is one string per row with its trailing NULs dropped. Record variables are read
  record by record from their interleaved layout, with the single-record-variable case unpadded as the format
  defines it.
- Attributes (units, scale factors, fill values) are read past, not applied. At most ten million elements per file.
- Left: NetCDF-4 (an HDF5 file), HDF5, Zarr and SQL/MDA's array operations.
