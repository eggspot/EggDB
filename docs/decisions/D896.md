## D896 ORC union columns — Decided by the code-only session (2026-11-12, D355); follow-up of D735 and D836

- `read_orc` and `eggdb import --orc` now read ORC union columns (type 13), at the top level and inside lists, maps
  and structs: the union's `DATA` stream holds one tag byte per present value (byte run-length encoded), and each
  variant's child column holds the values of the rows with its tag, in order. Each value is written as JSON text,
  `{"tag": n, "value": v}`, since the variants may have different types and the tag tells them apart (Hive shows
  unions as `{n: v}`); a null union is SQL `NULL`.
- A tag past the union's variants, or more tags than a variant has values, fails the read as a damaged file.
