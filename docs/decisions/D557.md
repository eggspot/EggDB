## D557 Zero-column tables in the PostgreSQL dialect — Decided by the code-only session (2026-11-11, D355); roadmap M6a, D308

PostgreSQL accepts `CREATE TABLE t ()`, a table with no columns that columns are added to later,
and SQLAlchemy's suite creates one. The parser required at least one column or constraint between
the parentheses. In the PostgreSQL dialect an empty list is now accepted and makes a table with no
columns; rows go in with `INSERT ... DEFAULT VALUES`, are counted and deleted like any others, and
`ALTER TABLE ... ADD COLUMN` gives them columns. The other dialects still refuse it, as MySQL, SQL
Server, Oracle and SQLite do.
