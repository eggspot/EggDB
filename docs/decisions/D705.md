## D705 read_arrow — Decided by the code-only session (2026-11-12, D355); roadmap M11, the file readers in SQL (D29, D703)

- `read_arrow(path) AS t(name type, ...)` (PostgreSQL dialect) reads an Arrow IPC file or stream through the
  session's file reader (D703) with `eggdb-arrow`'s reader (dictionary-encoded and LZ4- or zstd-compressed batches
  included, D640 and D641), and returns its rows the way `read_parquet` does: declared columns by name, `NULL` for
  missing ones, values cast to their declared types.
- `eggdb-sql` now depends on `eggdb-arrow`, and through it on `eggdb-storage` for the zstd and LZ4 decoders; neither
  depends on `eggdb-sql`.
