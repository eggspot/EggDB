## D808 Deleting CQL map entries and list items — Decided by the code-only session (2026-11-12, D355); roadmap M16, CQL collections (D19, D218)

- `DELETE m[k], c FROM t WHERE ...` and `DELETE l[i] FROM t WHERE ...` parse into a statement's element deletions
  next to its whole-column deletions (`Statement::Delete.elements`).
- A map entry is removed by keeping every stored entry whose key differs (`item.value -> 0 <> to_jsonb(k)`); a list
  item by the jsonb `#-` operator at that index. Keys and indexes may be bind markers. Deleting an element of a set,
  tuple or scalar column is refused, and primary key columns are refused as for whole-column deletes.
