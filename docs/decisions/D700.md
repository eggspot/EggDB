## D700 MySQL SET member checks — Decided by the code-only session (2026-11-12, D355); roadmap M10, MySQL's types (D19, D646, D684)

- A MySQL `SET('a', 'bb', ...)` column now gets an implicit check like D684's `ENUM` one: every comma-separated
  element of a stored value must be one of the members, compared case-insensitively as MySQL's default collations
  compare them. The empty string (the empty set) and `NULL` pass.
- The check calls the internal function `eggdb_mysql_set_members(column, 'a,bb,...')`, which is also its stored text,
  so the check reads back from the catalog like the others.
- Still left: storing a `SET` value's elements in member order without duplicates (MySQL rewrites `'bb,a,a'` as
  `'a,bb'`), numeric `SET` values, and `ENUM` ordering by member index.
