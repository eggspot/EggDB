## D1253 MySQL ENUM columns sort by member position — Decided by the code-only session (2026-11-18, D355); roadmap M10, MySQL's types (D646, D684)

- **What users get.** In the MySQL dialect, `ORDER BY` an `ENUM` column sorts by the members' order in the column's definition, as MySQL does: `ENUM('small', 'medium', 'large')` sorts small, medium, large, not alphabetically; the empty string (MySQL's error value) sorts first, NULL as usual.
- **How.** An `ENUM` is stored as `VARCHAR` with an implicit `CHECK` listing its members (D646, D684), so the members are read back from that check. When a MySQL `SELECT` over one table orders by a plain reference to such a column (bare, or qualified by the table or its alias), name resolution replaces the sort key with an internal function giving the value's position among the members (`eggdb_mysql_enum_position`, compared without case as MySQL compares `ENUM` values). What the query returns is unchanged; only the order is.
- **Left.** Sorting by an `ENUM` over joins and set operations, `ORDER BY` an alias or position that names one, `MIN`/`MAX` and comparisons by index, and `ENUM` values used as numbers.
- **Proof.** `mysql_enum_columns_sort_by_member_position` sorts three sizes ascending and descending; a unit test checks positions, a value that is no member and NULL.

**Status:** code written, unbuilt (code-only mode, D355).
