## D939 Key-value transactions and collections in the Swift package — Decided by the code-only session (2026-11-13, D355); roadmap M4, collections in the drivers (D292), follow-up of D930 to D938

- `drivers/swift/Sources/EggDB/KeyValue.swift` adds `KeyValue(path:readOnly:)` (`begin(writing:)`, `read { }`,
  `write { }` committing when the closure returns and rolling back when it throws, `close()`) and `Transaction`
  (rolled back when it ends without `commit()`, including on deinit), over the C API module `CEggDB`.
- A transaction has `get`/`getText`, `put` (bytes or text, `timeToLiveMs`), `delete`, `scan(ScanRange, collection:)`
  (start, end, prefix, reverse, end inclusive, limit; returning key and value tuples), `createCollection`,
  `dropCollection`, `renameCollection(_:to:)`, `collections()` and `collectionStats`; errors are `EggDBError`, as for
  SQL. Keys and values are `[UInt8]`; buffers from the C API are copied and freed at once.
