## D638 Huffman-coded literals in the Zstandard encoder — Decided by the code-only session (2026-11-12, D355); roadmap M2, D171, D357

D357's encoder wrote every compressed block's literals raw, so text with few repeats compressed
little: lowercase letters with no matches stayed at full size, where a zstd library halves them.
The decoder already reads Huffman-coded literals (RFC 8878, section 4.2).

- A new `encode_huffman` module builds the literals section with a Huffman tree of its own
  (`Compressed_Literals_Block`).
- Code lengths come from a Huffman tree over the bytes' counts. When a length passes the format's
  11 bits, the counts are halved (keeping every used byte at least 1) and the tree is rebuilt.
  Each tree is still a complete prefix code, so the weights always leave a power of two for the
  implicit last symbol.
- Codes are assigned the way the decoder reads them and as the RFC's example shows: by weight from
  lowest, and by byte value within a weight.
- The tree's weights are written directly, four bits each, for every byte below the highest
  used one. That covers literals whose bytes are all 128 or below (text, digits, most identifiers).
  Higher bytes would need FSE-compressed weights, and their blocks keep raw literals for now.
- Up to 1,023 literals whose coded size also fits in 1,023 bytes go in one stream, with the 3-byte
  header. Others go in four streams with the 6-byte jump table, the first three a quarter each
  (rounded up), and the header sized to the larger of the two sizes (3, 4 or 5 bytes).
- Streams are written last literal first, so the decoder, reading backward from the end marker,
  meets them in order.
- A block uses the Huffman section only when it is smaller than the raw one.
- Tests:
  - the length limit and completeness (Fibonacci counts that would need 29 bits);
  - the RFC's canonical code example;
  - round trips of random letters, skewed text, high bytes and two bytes;
  - random letters shrinking below 70%.

**Status:** code written, unbuilt (code-only mode, D355).
