## D852 Blosc bit shuffle — Decided by the code-only session (2026-11-12, D355); follow-up of D806

- Blosc 1 chunks with the bit-shuffle flag (`0x04`) now decode: each block's bits are transposed back from bit rows
  (for each byte of the element, for each bit, one bit per element, least significant first) to elements, the
  inverse of the bitshuffle library's transform that Blosc calls. Byte shuffle and bit shuffle each apply only with
  their own flag; bit shuffle applies at a type size of one too.
- The element count follows Blosc's two formats: from format version 3 the bits of the largest multiple of eight
  elements are transposed and the rest of the block is copied; version 2 transposes a block only when its element
  count is a multiple of eight and copies it otherwise.
- A header with both shuffle flags set marks a Blosc2 extended header, which is still refused.
