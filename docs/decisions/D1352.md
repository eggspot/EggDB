## D1352 Cypher on the property graph from the CLI and MCP — Decided by the code-only session (2026-11-25, D355); roadmap M6d "Tools that query documents, search indexes, vectors, graphs and keys in their own query languages (D10, D11)", the graph part

- **What users get.** `eggdb graph get <file> <cypher>` runs one Cypher query that only reads on a read-only open of the file's property graph (the collection `graph0` that Bolt and Gremlin serve); `eggdb graph run` runs one that may write in one write transaction. Both print the rows tab-separated with a header, or one JSON object with `columns` and `rows` under `--json`. Agents get the twins `graph_get` (every server) and `graph_run` (with `--allow-write`).
- **Safety.** `graph_get` opens the file read-only and runs the query with `read_only`, so the graph engine refuses a query that writes before it runs (D206); the tool answers `read_only` and points at `graph_run`. `graph_run` asks `confirm: true` for a query whose words include `DELETE`, `REMOVE` or `DROP` (`DETACH DELETE` included), as `rdf_run` does for SPARQL (D1014): a whole-word check that may ask for a query that only mentions the word in a string, never misses one that deletes. The check is `ConfirmCheck::GraphDelete` in the registry.
- **JSON form.** `eggdb_graph::result_json` writes a result, shared by the CLI and the MCP opener, so tool and command print the same values: nodes `{id, labels, properties}`, relationships `{id, type, start, end, properties}`, paths `{nodes, relationships}`, temporal values and points as their Cypher text, and floats that are not finite as text, since JSON has no NaN.
- **Limits.** One call returns at most 1 MiB of rows; the tool cuts whole rows and says `truncated`. Parameters (`$name`) are not taken yet: queries carry their values inline.
- **How.** `DatabaseOpener::cypher(text, write)`, default `None` (answered `not_supported`), as D1014's `sparql` hook; `eggdb mcp`'s file opener runs it on `DatabaseKeyspace` with the graph's prefix. The noun `graph` joins `eggdb`'s nouns, with `graph_error` as its error code.
- **Left.** Documents (MongoDB's query language), search indexes (the Elasticsearch query DSL), vectors and keys (RESP commands) as tools of their own; Cypher parameters; `graph_get` on `eggdb serve`'s MCP endpoint.
- **Proof.** The command model's parity test creates two people and a relationship with `eggdb graph run`, compares `graph_get` with `eggdb graph get --json`, refuses a write through `graph_get` and through `graph_run` on a read-only server, creates and (after `confirm: true`) deletes a node through `graph_run`, reports a syntax error as `graph_error`, and counts the people left; a unit test pins the JSON form, and the tools list counts 13 tools read-only and 25 with `--allow-write`.
