## D1202 Apache Atlas's API, read-only — Decided by the code-only session (2026-11-17, D355); roadmap M6c, the Apache Atlas and OpenMetadata APIs (D51)

- **What users get.** Beside D1201's OpenMetadata API, the REST listener answers Apache Atlas's v2 API under `/atlas/api/atlas/v2`: `search/basic` (`typeName=rdbms_table`, `query` matching table names), `entity/guid/<guid>` (a table with its columns as `referredEntities`, each with its `data_type`) and `lineage/<guid>` (relations from `eggdb_catalog.lineage`). Entities use Atlas's built-in `rdbms_table` and `rdbms_column` types; qualified names are `<database>.<schema>.<table>@eggdb`, and guids are the stable UUIDs of D1201 made from them.
- **Rights.** Read by the caller's own session, as D1201.
- **Left.** Writes, type definitions (`types/typedefs`), DSL search, classifications from glossary terms, and `rdbms_db` and `rdbms_instance` entities.
- **Proof.** A unit test finds a table by search, reads its entity with a column's type, and gets 404 for an unknown guid.

**Status:** code written, unbuilt (code-only mode, D355).
