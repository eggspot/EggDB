## D690 An XML parser and XPath 1.0 for xpath(), EXTRACTVALUE and EXISTSNODE — Decided by the code-only session (2026-11-12, D355); roadmap M9 XML documents with XPath (D38), M10 Oracle's XML functions

- `eggdb-sql/src/xml_path.rs` holds EggDB's own XML parser and XPath 1.0 evaluator, with no dependency.
  - The parser reads elements, attributes (quoted either way, no duplicates), text with the five named entities and
    numeric character references, CDATA, comments and processing instructions; it skips the XML declaration and
    `<!DOCTYPE ...>` (no DTD is read or expanded, so no entity can expand into a large or external document). Depth
    stops at 512 and size at a million nodes; mismatched or unclosed tags are `2200M` errors.
  - XPath covers location paths with the child, descendant, descendant-or-self, self, parent, ancestor,
    ancestor-or-self, attribute and sibling axes and their abbreviations (`//`, `.`, `..`, `@`); name, `*`, `text()`,
    `node()`, `comment()` and `processing-instruction()` tests; predicates with positions and `last()`; unions;
    arithmetic; comparisons with XPath's node-set rules; and the core functions (`count`, `position`, `name`,
    `local-name`, `string`, `concat`, `contains`, `starts-with`, `substring*`, `string-length`, `normalize-space`,
    `translate`, `not`, `boolean`, `number`, `sum`, `floor`, `ceiling`, `round`).
  - Namespaces are not resolved: a name test matches the element's qualified name, or its local part when the test
    has no prefix, so documents with a default namespace need no namespace array. Variables and the
    `following`/`preceding` axes are left out.
- Functions, in every dialect:
  - PostgreSQL: `xpath(path, xml [, namespaces])` returns a `text[]` of the matching nodes serialized (or the one
    string, number or boolean result), `xpath_exists(path, xml)`, and `xml_is_well_formed`,
    `xml_is_well_formed_document` and `xml_is_well_formed_content`. The namespace array is accepted and ignored.
  - Oracle `EXTRACTVALUE(xml, path)` and MySQL `ExtractValue(xml, path)`: the text directly inside the matching nodes,
    joined with spaces when several match (MySQL's rule; Oracle raises ORA-19025 there), and `NULL` when none does
    (Oracle's; MySQL returns an empty string). Oracle `EXISTSNODE(xml, path)` returns 1 or 0.
- Still left: `XMLTABLE`, `XMLQUERY` and XQuery, and the `XMLType` and PostgreSQL `xml` types. MySQL's `UpdateXML`
  came next (D691).
