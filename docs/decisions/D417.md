## D417 MySQL's `date + INTERVAL n unit` operator — Decided by the code-only session (2026-11-11, D355); roadmap M10

- In the MySQL dialect, `INTERVAL expr unit` (not followed by `(`, which stays MySQL's `INTERVAL()`
  function) is parsed as an interval operand, and the additive operators fold it into the date
  functions of D415: `d + INTERVAL n unit` and `INTERVAL n unit + d` become `DATE_ADD(d, INTERVAL n
  unit)`, and `d - INTERVAL n unit` becomes `DATE_SUB`. The result types and every unit are D415's.
- An interval operand left anywhere else (`SELECT INTERVAL 1 DAY`, `INTERVAL 1 DAY - d`) is a
  syntax error when evaluated, as MySQL refuses it when parsing.
