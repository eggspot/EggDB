# docs/ux: the EggDB client's design

Every screen a user sees is designed by Claude Fable before it is built (CLAUDE.md note 14, D15).
One file per surface or slice; a new slice gets its own file beside these and a line here.

| File | What it holds |
|------|---------------|
| [client-brief.md](client-brief.md) | Fable's brief for the whole client: principles, the main window, the slices in order, the familiar layouts, the design system summary, motion, errors, acceptance criteria |
| [first-screen.md](first-screen.md) | The first slice to build: a native window (macOS, Windows, Linux, browser) with the static connect card, every rect and token, the focus ring, keyboard order, the accessibility tree, 2× rendering, tests (built in `eggdb_gui::connect_screen`, shown by the `eggdb-gui` binary in an X11 window on Linux and the BSDs, a Win32 window on Windows and a Cocoa window on macOS, D256) |
| [workspace.md](workspace.md) | The slice after the first screen: the connect card's actions (open, create, browse, drop, a server URL, progress, failure, success), the query tab (dialect pill, run, run all, stop, status line, inline errors), the virtualized results grid (cells, keys, selection, copy as TSV or INSERT, the truncated banner), the object browser and inspector, the plan view, pointer and clipboard, accessibility roles and announcements, and a checklist testable on PNGs and accessibility-tree dumps |
| [gui.md](gui.md) | The desktop GUI: design tokens (colours, spacing, radii, type), the main window at 1280 × 800 as a golden image, components and states, the connect screen, shortcuts, motion, accessibility |
| [gui-layouts.md](gui-layouts.md) | The familiar layouts (works like SSMS, pgAdmin, DBeaver, DataGrip, MySQL Workbench, Compass, Redis Insight): regions, shortcuts, labels, trademark note, switching |
| [cli.md](cli.md) | The `eggdb` command-line tool: one-shot commands, output for a terminal and for a pipe, errors |
| [ui.md](ui.md) | `eggdb ui`: the full-screen terminal UI for browsing and editing a database file |
| [playground.md](playground.md) | The browser playground: the GUI's query and result alone on one static page |
| [command-model.md](command-model.md) | The Egg command model shared with EggOS: verbs, answers, errors and safety fields for people and agents (D143) |
| [polish.md](polish.md) | M6e leftovers: rows streamed into the grid with pages on scroll and mid-stream errors, the value view's selection and SQL type names, scrollbars that hide and fade, the editor's scrollbars, pointer cursors, tooltips, every splitter as a `Tab` stop in every layout, the rail's roles, the fades, the frame scheduler, the spinner and sweeping bar, reduced motion from every source (D275, D310, D311) |
| [connections.md](connections.md) | Connecting over MySQL and TDS, `rediss://` with `RESP · TLS`, the `Certificate check` dropdown (`verify-full`, `verify-ca`, encrypt only) with a CA file, the password field's `Show` button, recent connections in the sidebar with the OS credential store (D274, D329) |
| [data-models.md](data-models.md) | Every data model as a model tab: documents (filter and pipeline, cards, JSON tree, grid), search (query DSL, hits with scores and highlights), series (a control bar and a line chart), graphs (Cypher, a graph canvas), vectors (kNN), queues and streams, the RESP aggregate value view, the six chart tokens (D15, D276, D329) |
| [editor-and-plan.md](editor-and-plan.md) | Completion (the list, ranking, the function help pane), error help with `replace` and `statement` fixes and the `Fix ▾` menu, lint warnings; the plan view's per-step loops and totals, Oracle's `DISPLAY_CURSOR`, the plan tooltip in the accessibility tree (D275, D277, D312, D329, D1350) |
| [grid-editing.md](grid-editing.md) | Editing in the grid: when a result is editable, the cell editor, the value view's `Edit`, pending changes and their marks, the pending bar, generated statements, `Apply` in one transaction, errors and stale rows, adding and deleting rows, keys and confirmations; tokens `warningFill` and `errorFill` (D15) |
| [data-transfer.md](data-transfer.md) | The Import wizard (CSV, JSON lines, Parquet, SQL dumps, SQLite, mongodump, Redis AOF), the Export dialog, the Backup dialog, the Restore wizard and the Jobs tray, each showing the `eggdb` command it runs (D13, D15, D42) |
| [admin-screens.md](admin-screens.md) | Page tabs (the shape of every non-query screen); users and permissions (roles, grants, column grants, row policies, masks, `Test as`), monitoring (status tiles and charts, sessions, locks with wait chains, slow queries) (D15, D22, D25, D237) |
| [assistant.md](assistant.md) | AI help: the Assistant panel as an MCP client to the built-in server, cards for answers, statements and tool calls, the grants pill, confirmation cards with `Deny` as the default, the toolbar's agent chip and the Activity log from the audit log (D11, D15, D45, D121, D255) |
| [layouts-contents.md](layouts-contents.md) | The familiar layouts' own region contents (SSMS's `F4` properties, pgAdmin's Query Tool toolbar, DBeaver's run column, DataGrip's Services header, Workbench's output rows, Compass's filter bar and cards, Redis Insight's result cards and CLI), hidden regions and toggles, the `View` menu with `View > Layout`, the connect screen's `Coming from another client?` row (D309) |
| [localization-and-window.md](localization-and-window.md) | The strings catalog, English and Arabic, bidi and shaping, what mirrors and what does not, following the OS's theme live, the remembered window frame, small screens and touch (D15, D42, D256) |
| [er-view.md](er-view.md) | The interactive ER view: cards with columns, indexes and checks, views and schema groups, crow's-foot relationships, layered auto layout, keyboard navigation, PNG, Mermaid and DOT export (D237) |
| [console.md](console.md) | The admin web console served at `/console/` (sign-in, the `Console` group, backups, settings, logs) and its relation to the desktop client; the catalog, lineage and master data pages over `eggdb_catalog` (D42, D244, D51) |
| [notebooks-and-builder.md](notebooks-and-builder.md) | SQL notebooks as Markdown files with query, text, chart and parameter cells, one kept session, exports; the one-way visual query builder with ER cards, joins and a columns grid writing SQL live (D42) |
